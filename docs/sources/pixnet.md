# 三國瑜雲（Pixnet）数据

作者博客：https://vincecarter0315.pixnet.net 。2019-06 整理，繁体。结构化结果在同目录的 JSON 里。

## 武将

- 五维和适性：https://vincecarter0315.pixnet.net/blog/posts/14215526609 （按序号；按综合能力的是同一张表）
- 履历：https://reganlu007.github.io/san11/man.html
- 文件：`officers.json`，850 人，序号 0–849

0–669 是史实武将，800–831 是通关教学模式后的非三国人物。670–698、763–799、832–849 是空槽，`slot` 为 true。699–762 是皇帝、在野、异族和路人，瑜云那张 702 人的表没有收。

五维、适性、特技以瑜云为准，和人物表核对过，只有 249 号用字不同：瑜云「朱儁」，人物表「朱雋」。综合值等于五维之和。347 人有特技。

人物表补上的字段：性别、登场年、生卒年、自然死、血缘、父母、配偶、义兄、世代、亲近、厌恶、五项能力变动、出身、得意话题、义理、野望、起用、性格、音声、口调、汉室、战略倾向、地元执着、头像编号。父亲等栏有时是「20 02」这种内部编号，原样保留。

## 城市

- https://vincecarter0315.pixnet.net/blog/posts/14215527290
- 文件：`cities.json`，42 城

最大士兵、金、粮、耐久、州、邻接来自瑜云，金粮耐久与日文 wiki 的上级表一致。开发地、分片、港关数、特色来自 [都市データ](https://w.atwiki.jp/sangokushi11/pages/77.html)。云南是 15 格。北海、建业、会稽的 wiki 没有写出分片。

## 特技

- 等级和说明：https://vincecarter0315.pixnet.net/blog/posts/14215526666
- 2018 介绍（气力数字、使用说明）：https://vincecarter0315.pixnet.net/blog/posts/14186697920
- 游民星空持有人名单：https://www.gamersky.com/handbook/200603/21610.shtml
- 文件：`skills.json`，100 个

`effect` 用等级表。`introEffect` 用 2018 介绍，扫荡是气力 −5，威风是 −20。持有人从 `officers.json` 的特技栏汇总。游民星空名单照录在 `gamerskyHolders`，错字不改。

和等级表说得不一样、实现时不能并成一句的：

| 特技 | 等级表 | 另一份 |
|---|---|---|
| 乱战 | 森林中会心 | 2018 和游民星空写攻击力上升。日文特技页写「森で攻撃時クリティカル」，规则采用会心 |
| 待伏 | 伏兵成功会心 | 2018 和游民星空都写敌必混乱 |
| 妙计、秘计、深谋 | 计略成功会心 | 游民星空写必混乱；2018 介绍和等级表一样，是暴击 |
| 屯田 | 关、港士兵不消费兵粮 | 2018 和游民星空写消费减少 |
| 论客 | 容易进入舌战 | 2018 和游民星空写舌战效果增加 |
| 风水 | 不容易出现蝗灾、瘟疫 | 游民星空和 2018 只写疫病 |
| 捕缚 | 没有强运或名马才必定捕获 | 2018 和游民星空写必然捕获 |
| 白马 | 未研究骑射也能骑射，并且骑射会心 | 2018 和游民星空没写会心 |
| 飞将 | 战法会心 | 2018 写成只有枪、戟、弩、骑 |
| 神将 | 普通攻击和战法会心 | 2018 写成普通攻击或枪、戟、弩、骑 |

连击的持有人，人物表比游民星空多一个傅彤。运搬在游民星空里把李丰写了两次。

## 宝物

- 剧本位置：https://vincecarter0315.pixnet.net/blog/posts/14215526684
- 游民星空：https://www.gamersky.com/handbook/200603/21602.shtml
- 文件：`treasures.json`，43 件

位置和是否登场用「英雄集结」「女流之战」。游民星空写明除玉玺（洛阳）、铜雀（平原）外地点大多随机。剑名瑜云是「雌雄一對劍」，游民星空写作「双股剑」；长柄瑜云是「蛇矛」，游民星空是「丈八蛇矛」。

## 爵位官职

- https://vincecarter0315.pixnet.net/blog/posts/14205896702
- 文件：`ranks.json`，80 个官职

空白格按原表 rowspan 向下填。皇帝指挥 15000、要 24 城，王 14000 / 20 城，公 14000 / 18 城，一直到无爵位 10000 / 0 城。

游民星空末段功绩列错位。这里用瑜云：左仆射、右仆射、典农校尉、议郎是指挥 5000、政治 +1、俸禄 10、功绩 0；奋威、长水、破贼、武卫校尉是指挥 6000、俸禄 10、功绩 0，没有能力上升。

战法最终伤害、计略命中、地图坐标，这些页面都没有单独的数值表。
