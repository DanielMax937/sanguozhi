## 攻防面板

```
攻击 = floor(部队武力 / 100 × 兵种基础攻击 × 适性 × 技术)
防御 = floor(部队统率 / 100 × 兵种基础防御 × 适性 × 技术)
```

适性取队内该兵种最高者：S 1.0，A 0.9，B 0.8，C 0.7。剑兵没有适性，系数 0.6。

精锐是把系数换掉，不是在武力 100 的结果上再加 10。武力 100、适性 S 的枪兵，精锐前攻击面板是 95，精锐后是 105。戟的优势在防御系数（基础 105，精锐后统率 ×1.15），没有另外一条近战普攻减伤。

最终伤害没有出处。存疑稿里的封闭式子，和出处不冲突的部分按下面采用。攻防面板仍用上一节，不用「枪兵系数 1.0、面板 100」。克制仍是枪克骑、骑克戟、戟克枪，且只乘在战法上，不乘在普通攻击上。不用枪克骑、骑克弩、弩克枪，也不另给戟兵近战普攻减伤。火矢的点燃伤害和计略伤害不乘兵力。

存疑，普通攻击和战法：

```
底数 = max(0, 攻击 − 防御) × sqrt(兵力 / 1000)
战法底数 = 底数 + 战法表「对部队」× 10
伤害 = 底数或战法底数 × 暴击 × 克制
```

普通攻击用底数。战法用战法底数。暴击不是会心时为 1，会心为 1.15。克制优势 1.15，劣势 0.85，没有克制为 1。普通攻击的克制固定为 1。「对设施」不走这条兵力式子。稿里的攻防差系数、地形修正、随机波动没有给出数字，这三项按 1，不另造范围。

## 战法

暴击伤害 ×1.15。螺旋突暴击必定混乱。火矢暴击必定点燃。

克制只作用于战法，不作用于普通攻击。枪克骑，骑克戟，戟克枪。弩不在这个三角里。

枪兵战法看目标所在格。目标在沙地，战法不能放。

飞将、神将和枪将、戟将、弓将、骑将一样，作用于对应的陆上兵种战法。兵器看工神，水军看水将、水神。

待伏：伏兵成功变为暴击。暴击是气力 −20，并且伤害提高。混乱仍然是概率，暴击也不变成必定混乱。

妙计、秘计、深谋按计略会心处理。扰乱、伪报的暴击把状态延长到至少 2 回合。火计暴击延长燃烧。不把这三条写成「所有计略都附带混乱」。

## 兵粮

PC-PK1.1 每旬耗粮：

```text
野外战斗部队：兵力 / 10
输送队：兵力 / 20
城市/港/关驻屯：兵力 / 40
港/关有屯田：0
```

上式均是原函数的浮点常量展开；最终经 `00707A74` 整数化，兵力>0时最低耗粮1。

阵系设施对**战斗部队**：

```text
无：100%
阵：约83.33%（约减16.67%）
砦：约66.67%（约减33.33%）
城塞：50%
```

攻略常写15%/30%/50%，PC fidelity实现使用原EXE常量。运输队源码直接跳过阵系减粮分支。

着火额外烧粮：

```text
野外：当前粮 × (6 - 部队政治×0.05) × 1%
据点：当前粮 × (6 - 太守政治×0.05) × 1%
```

再加正常兵力耗粮。无太守按政治0处理。

普通战斗部队携粮上限50000，和兵力无关。粮尽后会发生大幅逃兵，但旬级耗粮函数本身只负责扣粮到0，不负责扣兵；约每旬保留76%的旧式继续只作实测fallback。

多个阵/砦/城塞范围重叠时的 `0049D180` 选择优先级、粮尽逃兵原函数和最终浮点取整边界仍open。

## 部队编成

PC-PK1.1 的运行时部队固定有 `MainGeneralID + 2个SubGeneralID`，因此最多3名武将；`TroopType=0` 为战斗部队，`TroopType=1` 为输送队。

玩家战斗部队的兵力合法范围已由出征界面原函数 `00647250` 恢复：

```text
上限先取：
min(主将可指挥兵数, 据点现有兵力)

若兵种为枪/戟/弩/马：
再与据点对应兵装库存取 min

下限：
1兵
```

所以副将官职不叠加带兵；剑不按士兵数要求库存；枪戟弩马库存必须覆盖出兵人数。攻具、楼船、斗舰是按部队件数准备，不是按士兵数准备。

资源上限：

| 类型 | 兵力 | 金 | 粮 |
|---|---:|---:|---:|
| 战斗部队 | 主将指挥上限，并受据点/数量型兵装限制 | 10000 | 50000 |
| 输送队 | 60000 | 100000 | 500000 |

输送队可携最多3名武将；所携兵装是货物，不会因为装了枪/马/攻具而变成战斗部队。

同一战斗部队可以同时保存陆上与水上装备，进入河/海只切换当前使用 profile；离水后仍恢复陆上装备。最终出征资源提交、攻具/高级舰船扣还和输送兵装逐类容量仍 open。

## 补给与输送（E6）

输送到据点与野外补给是两条路径：到据点功绩+200（PC地址 `004BF522`）；野外补给功绩+100，并给率领输送队执行补给者统率经验+2。

PC版可在相邻后手动选择补给量；直接把己方战斗部队设为输送移动目标时会自动向目标上限方向补给。CS版不能自由调量，其3000兵/1000金等固定补给数字仅属CS版本规则。

枪/戟/弩/马补兵同时受目标剩余指挥容量、输送队可用兵力、对应兵装库存约束；剑兵没有一兵一剑库存约束。补兵后气力按新旧兵力人数加权平均。

输送到据点必须服从据点兵/金/粮/兵装上限；完整资源finalizer、超限货物处理、12类运输兵装逐类型容量和气力非整除取整仍open。军事府使输送AP减半，基础AP完整函数仍待恢复。

## 训练与气力

PC-PK1.1 训练闭式：

```text
S = 最多3名执行武将武力和
M = 执行武将最高武力
D = min(100, 20 + floor(据点兵力/2000))

基础训练 = floor((S+M)/D) + 3
有练兵所 = floor(基础训练×1.5)
实际增加 = min(训练值, 气力上限-当前气力)
```

训练只看武力，不看统率。普通20AP；PK城市有军事府10AP；每名执行武将武力经验+2、功绩+50并置已行动。据点被标记为已训练。技巧P = `floor(实际增加气力/2)+5`。执行函数没有固定金钱支出。

据点和部队气力上限均为100，研究熟练兵后为120；研究完成不会自动把当前气力补到120。

野外每旬恢复：己方军乐台范围2内+10；若部队有诗想则军乐台恢复合计+20；不在军乐台恢复时，奏乐+5。奏乐不与军乐台叠加。没有来源支持“普通城内每旬自然+5”，因此不采用。

扫荡：攻击命中敌军气力-5。威风：-20，和扫荡同时存在时威风优先。昂扬：击破敌部队自身+10。怒发：受到敌方战法自身+5。

补兵会按新旧兵力对气力做人数加权平均。完整训练资格gate与已训练状态重置caller仍open；详见 `docs/rules/19-training-morale.md`。

## 应射（E10）

应射是弩兵系 Lv2，技巧ID9，PC地址 `00584DC8`。

当前采用：

- 仅应射势力的弩兵 profile；
- 触发箭类攻击，而非所有远程伤害；
- 弩普通射击、骑射、火矢/贯矢/乱射等箭类战法可触发；
- 必须满足防守方当前正常攻击射程与地形合法性；
- 支援攻击不触发应射；
- 混乱/伪报不能正常应射；
- PCPK“急袭”可50%规避应射反击伤害。

因此“强弩3格射击打2格射程应射弩兵”可以单向攻击；攻击者位于防守方不可攻击的森林格时也可能无法应射。

应射本质上是一次合法反击机会，不保证固定弩箭形式。水上 active profile、完整PC caller以及双方应射+连战的PC链序仍open。详见 `docs/rules/25-response-fire.md`。

## 技巧研究天数（E11）

研究时间不是固定表。超级难度实测显示，3名参与武将的相关能力和在：

```text
70 / 140 / 210 / 280
```

处分档。

能力和210、无人材府时有一组实测锚点：

```text
30 / 40 / 60 / 90日
```

但测试技巧系未注明，不能覆盖全部36项。

人才府是源码精确：

```text
-20日
最低10日
```

即 `finalDays=max(10,baseDays-20)`。

攻略通常显示时间还分两组：

```text
枪/戟/弩/骑/练兵：30/40/60/90
发明/防卫/火攻/内政：40/50/70/100
```

攻略明确说明这些“并非固定研究时间”。

完整PC函数、超级全矩阵、初级/上级和属性getter层仍open；禁止用线性插值补未知格。详见 `docs/rules/26-technique-research-time.md`。

## 异常状态（E13）

PC-PK1.1 部队结构明确保存：

```text
+0x24 状态：0正常 / 1混乱 / 2伪报
+0x28 状态剩余计数
```

每旬原函数 `00599B90` 的顺序是：

```text
先执行异常行为
→ 标记已行动
→ 普通位置 remaining -1
→ PK合资格己方阵/砦/城塞范围 remaining -2
→ 最低0
→ 0时恢复正常
```

所以自然恢复**不是每旬随机掷骰**，也不读取智力。

混乱：不能反击，战法必中，控制区域消失；PC-PK1.1 `00496570` 还确认攻击、防御、建设力统一×0.8。本旬异常处理时，若尚未行动会直接被标记为已行动。

伪报：不能反击，战法必中，控制区域仍在；若本旬尚未行动，会先朝所属据点执行退却，再标记已行动。不是“走到城下才解除”。

少兵自动混乱路径的初始持续计数已源码确认：

```text
GetRandomX(2)+1 => 1或2旬
```

但这不能套给普通计略。普通伪报/扰乱成功后的初始持续分布仍 open；日文 Wiki 的稳定边界只是“数回合”，会心至少2回合。

对混乱中的部队发起单挑，对方更容易应战。

完整地址、版本边界与工程 fallback 见 `docs/rules/28-status-duration-recovery.md`。

## 编成和携带

带兵上限用主将当前官职的指挥兵力，副将不另加上限。无官职基础指挥兵数已确认是5000；军制改革再+3000，因此无官可到8000，普通最高官职/皇帝可到18000。

部队能力合成在 PC-PK1.1 原函数中分层处理：多将部队先检查三组双向嫌恶，任一命中则五维全部只取主将；无嫌恶时，统率/武力走主副将关系补正，智力/政治/魅力直接取三人最高。六兵科适性始终取三人最高，即使存在嫌恶也不取消副将适性。普通/亲爱统武补正的 PC 地址分别确认差值 1/4、1/2；血缘1/3、夫妻/义兄弟1继续采用精确跨平台实测。

剑兵不要求按士兵数准备库存。枪、戟、弩、马已确认属于数量型兵装，出征和补兵时库存必须覆盖相应士兵数；攻具和高级舰船按部队件数建模。

普通战斗部队兵粮上限50000、金上限10000；输送队兵力60000、金100000、粮500000。上述均已由PC-PK1.1地址/函数核定。

给部队补兵时，气力按新旧兵力人数加权平均。2500人、气力0，加2500名气力100的新兵后为5000人、气力50；非整除时的精确整数化仍open。

只有直接攻击击破对方，才能抢走对方携带的金和粮。出征中的武将不能奖赏。

## 训练（E4摘要）

训练只看最多3名执行武将的武力：
```text
D = min(100, 20 + floor(据点兵力/2000))
训练值 = floor((武力和+最高武力)/D)+3
有练兵所再 floor(×1.5)
```
最终增加不超过100/熟练兵120的气力上限。普通训练20AP，军事府城市10AP；每名执行者武力经验+2、功绩+50；技巧P=`floor(实际增加气力/2)+5`。

军乐台范围2每旬+10；诗想在军乐台范围使恢复合计+20；没有军乐台恢复时奏乐+5。旧“统率×0.15”“城内自然每旬+5”已撤回。完整规则见 `docs/rules/19-training-morale.md`。

## 攻城

可以削城的耐久，也可以削城里的兵。港关里没有兵时，一击就会陷落；大约 5000 剑兵能挡下一击。守军有余力就会出城。城外一支守军都不留，更容易把人引出来。城陷落后，城里的内政设施大部分被拆掉。

存疑，普攻扣耐久：floor(部队攻击力 × 适性 / 10)。稿里的兵种系数没有数字，按 1。冲车一类攻城战法单次约 300–800 耐久。投石单次约 200–500 耐久，并优先扣城兵。

存疑，陷落：耐久归零或城兵归零，当击陷落。城兵归零时，剩下的耐久留给占领方。耐久归零时，城兵清空，耐久重置为上限的 10%。

存疑，电脑守军：敌军进入 3 格内，城内兵力不低于对方 1.2 倍，且有武将和兵装，旬初出 1–3 支部队。否则死守。城外一支守军都不留时，更容易把人引出来，这条仍在。

堤防、港、关的耐久，没有太守就不恢复。恢复量看太守政治，没有系数。

云梯：对据点和建筑物的伤害增加。枪、戟、弩、骑 +40%，攻城兵器和舰船 +20%。对城市、港、关时，耐久和城兵都吃这个加成。

港和关的容量，研究港关扩展之前：金 10000，粮 100000，士兵和兵装各 30000。研究之后：金 40000，粮 400000，士兵和兵装各 60000。

## 外交和人事里已经能用的

太守、都督在正常玩法中不能直接点名任命，会自动决定。高置信排序是：候选中**可指挥兵数最大者优先，同值再比较统率**；另外有官职者相对完全无官职者存在优先边界。太守还存在君主/都督身份优先的长期实测。玩家可通过授官/撤官、军团编成间接影响结果。

军师与太守/都督不同：可以通过“军师”命令直接任免。官方要求智力 >=70；任免即时、0金、0行动力。军师属于势力级唯一 `AdvisorID`，不改变武将原本的太守/都督/一般 Identity。智力越高助言越准确，但精确正确率公式仍 open。

断绝同盟：技巧点 −50。当时留在对方领内的己方部队陷入伪报。

超级难度下，用论客把外交打成舌战的概率是 20%。初级和上级是 100%。

处斩本身**不会自动新生成嫌恶/报复关系**；但已有嫌恶并非与处斩无关：COM 君主与俘虏任一方向存在嫌恶时，长期实测会走必处斩分支。释放俘虏会加一点技巧点，加多少没有写。

黑市不降低治安，也不让贼更容易出现。主机版上它会提高探索到宝物的几率。次年 1 月强制拆除，要盖就在 1 月盖。拆掉不扣技巧点。

单挑（E14）：通用 PC-PK 导向连续核心已恢复。武力先经过非线性 `duelScore` 形成 `actionRatio(1..99)`，再进入方针命中/格挡、闪避、伤害与斗志计算；不是只看武力差。例：100/95 的 ratio=55，而80/75只有52。武力相同时 ratio=50，攻击/防御/斗志重视完整命中为12/7/10。普通格挡约取伤害一半，防御重视格挡按×3/10且最低1；闪避为0伤害。气合通用伤害×5/4、坚守×3/4；剑使斗志增长×3/2。完整式见 `docs/rules/29-duel-continuous-formulas.md`。长柄通用核心区分方天画戟×9/8与其他长兵×10/9。名马与俘虏、人物专属隐藏补正及主机版差异继续按单挑专项的版本边界。

太守的武力影响据点反击的伤害，没有系数。魅力影响征兵量、登用、行动力、新武将和登用后的初始忠诚、换季时治安下降，这些系数存疑稿没有单独给。奖赏见下。

## 舌战边界（E15）

可出牌数：

```text

70～79：4张
80～89：5张
```

心理伤害另算。进入舌战时：

```ts
attack =
  100
  + trunc(
      40*(我方智力-对方智力)
      /(131-我方智力)
    )
```

普通话题牌：

```ts
hpDamage =
  trunc(
    (attack + RandInt(5))
    * angerCoef
    * levelCoef
    * topicCoef
    /1000
  )
```

普通状态：

```text
levelCoef：小10 / 中15 / 大20
topicCoef：当前话题10 / 非当前6
angerCoef：10
RandInt(5)：0..4
```

同智力时，当前话题小/中/大约100～104 / 150～156 / 200～208；非当前约60～62 / 90～93 / 120～124。

大喝使用固定 `levelCoef=15, topicCoef=12`，同智力约180～187；诡辩用自己的attack配合对方普通话题牌模板反弹。无视本身不扣心理，只让对方怒气+30；镇静和激昂走独立怒气效果层。

完整结构见 `docs/rules/30-debate-psychological-damage.md`。

## 俸禄、忠诚和俘虏月度处理

忠诚真实值为 byte `0..255`，UI 只显示 `min(value,100)`；褒赏、宝物、事件等都修改真实值，不要在100处截断。

官职俸禄是**每月**结算，不是季度。`00590490 MonthlyIncomeAndExpend` 在每个城市/港/关先结算本月收入，再先付据点俘虏维护费，随后用 `0049F2A0` 汇总现役武将官职俸禄：

```text
本月收入
→ 据点俘虏维护费（50金/人）
→ 现役武将俸禄
→ 资金不足后果
```

俘虏维护并不是“有几个就一定全扣”。源码先算：

```text
可支付人数 = min(俘虏数, floor(当前金/50))
维护费 = 可支付人数×50
付不起人数 = 俘虏数-可支付人数
```

付不起的部分进入 `0058C320 -> 0058D1D0 -> 0058D430` 的释放/逃走处理；具体优先放谁仍 open。该循环按城市/港/关统计，野外部队携带的俘虏不进入据点维护列表。

现役俸禄总额不超过剩余金时直接全额扣除；若付不起，则进入 `0058D5E0` 欠薪/忠诚下降准备，并在后段 `0058C190` 处理忠诚。具体哪些武将掉多少仍 open，因此不使用旧“全城统一 -10～-30”。现有80个官职月俸表为10～60，见 `docs/sources/ranks.json`。

普通官职升降**本身不改变忠诚**；爵位授予/自称产生的忠诚变化是另一个势力事件。

官职表的功绩要求是原EXE的4000点阶梯（0～36000），人物功绩上限60000。官职能力加成由 `OfficeID -> AttrIncreaseType/AttrIncrease` 直接进入实际五维并最终封顶100。

自动封官 `005FAF00` 不是单纯按功绩排序：资格helper之后，真实忠诚<90直接排除；另有两个能力评分分支。带60/70/统智150门槛的是其中一个 caller 模式，不能无条件套到所有自动封官路径。完整细节见 `03-personnel.md#10-官职`。

己方普通武将的自然忠诚下降只在换季判定：与君主150环形相性差 `>=25`，或低/较低义理且高/较高野望。`仁政` 阻止同都市普通武将自然下降。

PC-PK1.1 `0058E510` 已恢复完整俘虏分支：

- 俘虏跳过季初限制，因此月初每月可判定；
- 俘虏跳过仁政；
- 亲爱/配偶/义兄弟/父母子女仍可免降；
- PK人心掌握以2/3概率免降；
- 进入数值分支后：`Random(0..2) + 符节台(2) + 特定君主义理/野望附加 + Random(0..2)`；
- 特定附加为：君主义理最低且野望最高时 `floor((4-目标义理)/2)`。

俘虏自然逃亡是另一条月初流程 `00582BE0`，发生在维护费之前：

```ts
if (CaptiveMonths < 2) noRoll
q = max(1, CaptiveMonths - 2)
stat = max(30, max(WAR, INT))
p = max(1, floor(q*q*stat/150))
```

只对有效城市/港/关中的俘虏执行，所以野外部队携带的俘虏不走这条自然逃亡判定。函数本地不封顶100，超100参数交给共用概率helper的边界仍 open。

## 击破时的伤亡与捕获

E16 已确认：**部队被普通攻击/一般战法/设施攻击击破后，不再额外套一个统一武将负伤/战死 RNG。** 原作 casualty 按专用来源分流：弩/井阑/舰船火矢、贯射、乱射走 `005974C0` 狙伤；猛者成功位移后50%负伤；业火种/业火球走 `00597350` 战死+独立负伤；骑兵突击/突进和单挑各走自己的专用结算。弩系狙伤为 `战法基础(0/1/2)+统武比较档(-2..1)+目标性格(0..3)+会心(0/1)-1`，理论峰值6%。完整式与火矢边界见 `docs/rules/31-non-cavalry-casualty-sources.md`。

但 PC-PK1.1 **击破捕获主公式已恢复**，不再使用旧“近战30% / 位移40% / 包围70%”作为主规则。

`004B1280` 的普通捕获路径：

```ts
stat = max(target.war, target.intelligence)

surround = 1
if (surroundingFriendlyUnits > 0 && !target.hasSkill("铁壁")) {
  surround = surroundingFriendlyUnits
}

context = (contextId === 3 || contextId === 4) ? 1.5 : 1.0
difficultyDiv = (superDifficulty && playerAttacksAI) ? 2 : 1

p = toInt(
  floor((120 - stat) / 3)
  * surround
  * context
  / difficultyDiv
)

if (attackerUnit.hasSkill("捕缚")) p += 100
p = min(p, 100)

if (isHalberdTactic) p += 30
p = min(p, 100)
```

已确认边界：

- 强运(skill 32)在部队击破捕获时是硬免疫；
- 捕缚在普通概率路径直接+100；
- 目标有铁壁时只取消“合围人数倍率”，不是绝对免疫；
- 戟兵战法最终+30；
- 超级难度只在玩家击破AI方向把普通概率除2；
- 日文Wiki稳定确认名马会反制捕缚，但主函数前置helper `004A0590` 尚未完成语义映射；
- 血路另走独立逃脱边界，部队壊滅与据点陷落不要混成同一硬免疫。

捕获公式中的 `contextId==3/4 -> ×1.5` 业务含义仍 open。

单挑俘虏率使用单挑章节自己的平台规则，不套用这组野战/据点捕获公式。

## 灾害和贼

城市灾害状态不是一次性随机扣资源，而是保存为 current / scheduled 两层 bit：疫病、蝗灾、丰作。

- 丰作：当前 flag 生效时，完整城市粮食 tick ×1.5，然后才进入征收、米道和港关20%。
- 风水：阻止所属都市新发生疫病/蝗灾；对已经发生的灾害不负责立即治疗。
- 祈愿：只确认提高所属都市发生丰作的倾向；精确概率倍率未恢复。
- 蝗灾：会破坏农场并造成兵粮损失。Lv1 农场被拆时扣30技巧P；Lv3不会被拆；Lv2边界、直接粮损与持续时间仍 open。
- 疫病：会减少驻军并恶化城内武将健康；精确兵损、患病RNG与持续时间仍 open。

撤回旧 provisional：`蝗灾5% / 疫病5% / 丰作10%`、`每年1月独立判定`、`疫病每旬病死5%～10%`、`30%武将患病`、`持续1～2季`。当前没有足够源码/官方/稳定实测支撑这些数字。

随机有害自然灾害只按疫病、蝗灾建模；堤防水攻属于固定地图机制，不属于随机洪水系统。

治安低于80可能出贼。贼/异族每旬精确生成概率、兵力、选格算法仍为 open；已生成的根城不会因为治安恢复到100自动消失。
