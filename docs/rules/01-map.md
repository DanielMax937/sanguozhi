# 地图、地形、移动、港关与水战

## 1. 世界地图

- `[COMMON]` 战略与战术使用同一张六角格地图。
- 每格至少需要：坐标、地形、高度、所属城市区域、是否可建、是否水域、是否着火。
- 当前 repo 尚缺原作完整六角格坐标与每格地形数据，这是完整模拟的最大静态数据缺口之一。

## 2. 地形与战法可用性

常见地形：草地、土/本道、荒地、砂地、湿地、毒泉、森林、栈道、间道、渡、浅濑、水域等。

### 目标格决定战法是否可用

- 枪：砂地不可；其余常见陆地可。
- 戟：常见陆地基本可。
- 骑：湿地、毒泉、森林、栈道等不可（不同资料对浅濑有平台差异，按数据表为准）。
- 弩：森林目标不可，除非特技/规则允许（如射手）。

## 3. 移动力

基础移动来自兵种表；地形按移动消耗扣除。

影响移动的主要技巧/特技：

- 强行：剑/枪/戟/弩/骑陆军移动 +5。
- 长驱：骑兵移动 +3。
- 操舵：水军及水上输送移动 +4。
- 运搬：输送移动 +5。
- 车轴强化：攻城兵器移动提高。
- `[PK]` 木牛流马：输送队移动提高。
- 难所行军：可通过间道、浅濑并降低栈道伤害。

## 4. ZOC（控制区域）

- 敌部队会形成阻碍/控制区域。
- 飞将、遁走等特技可忽略陆上 ZOC。
- 混乱部队的控制区域消失。
- 具体每种地形/单位的 ZOC 通行消耗仍应由地图实测锁定。

## 5. 高度

- 地图有高度差。
- 枪/骑的位移类战法成功率受自己与目标高度差影响；戟的方向相反。
- 原作完整高度表必须从地图数据提取，当前 repo 未完成。

## 6. 水陆切换

- 陆军进入可航行水域时，以携带舰船决定水上兵科；没有高级舰船时使用走舸。
- 水上使用水军适性与舰船战法，不能使用陆上枪/戟/弩/骑战法。
- 港是重要的水陆节点，港口及关隘可驻兵、存储金粮兵装，并可被攻陷。

## 7. 港关容量

`[COMMON]` 基础容量：

- 金 10,000
- 粮 100,000
- 兵 30,000
- 枪/戟/弩/马各 30,000

`[PK]` 研究“港关扩张”后：

- 金 40,000
- 粮 400,000
- 兵 60,000
- 各兵装 60,000

## 8. 地形伤害

当前采用（实测/候选）：

- 毒泉：约 1000 兵并降气力；解毒免疫。
- 栈道：每格造成兵损；难所行军降低/免除对应伤害。
- 落石：造成较大兵损并可能混乱；踏破降低伤害。

精确随机区间仍列入 `13-open-exactness.md`。
