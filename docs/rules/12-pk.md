# 威力加强版（PK）专属规则

本文件只列 **PK 新增或改变** 的系统。COMMON 规则见其他文件。

## 1. 新增内政设施（10 类）

`[PK][PC-PK1.1 reverse-engineered + confirmed-data]`

PK 新增：

```text
经济型：
大市场 / 鱼市场 / 黑市 / 军屯农

功能型：
练兵所 / 符节台 / 军事府 / 人才府 / 外交府 / 计略府
```

这些设施在无印不能直接使用。完整数据与逆向规则以 `02-economy.md#5-pk-新增十设施` 为权威入口。

核心行为摘要：

- 大市场：月金300；不吃造币；大都市限定、每城1座。
- 鱼市场：月金200；不吃造币；有港都市限定、每城1座。
- 黑市：月金80；不吃造币；可多座；翌年1月强制撤去。
- 军屯农：`floor(max(cityTroops,15000)/10)`；不吃谷仓。
- 练兵所：训练效果 ×1.5；只缩短舰船生产，不缩短攻具。
- 符节台：旬行动力恢复 +5；忠诚下降计算额外 +2。该 +2 位于通用忠诚下降分支，所以还存在“本方武将若本来进入季初自然掉忠流程，也会多掉2”的 PC-PK1.1 副作用。
- 军事府：源码目前明确确认训练/出征/输送 AP 减半，军事设施/陷阱设置费 ×0.8；不要在 C11 完成前把所有军事命令一律写成半 AP。
- 人才府：探索/登用 AP 减半；技巧研究 -2旬，最低1旬。
- 外交府：外交 AP 减半；亲善金减半；不增加外交成功率。
- 计略府：计略 AP 减半；流言公式中的内部参数 10→12，并非最终成功率固定 +20 个百分点。

跨系统细节分别见：

- 练兵所：`04-military.md`
- 符节台：`03-personnel.md`
- 外交府：`07-diplomacy.md`
- 计略府：`06-strategy.md`

## 2. 吸收合并

`[PK][official-confirmed + reverse-engineered-structure]`

PK 新增独立“吸收合并”行动（actionId=1）。完整规则以 `02-economy.md#6-pk-吸收合并` 为权威入口。

核心约束：

- 仅市场、农场、兵舍、锻冶、厩舍五类；
- 必须相邻同类设施；
- 被吸收侧必须是 Lv1；
- 仅允许 `Lv1+Lv1→Lv2`、`Lv2+Lv1→Lv3`；
- Lv2+Lv1 时必须以 Lv2 为升级主体；
- 最高 Lv3；
- 城市周围2格内有敌军时不能执行；
- 固定消耗 10 行动力 + 100 金；
- 政治≥70 为10日，否则20日（当前为 empirical-high timing）；
- 合并中升级主体继续按前一级效果生效；
- Lv2 / Lv3 效果分别为 Lv1 的 1.2 / 1.5。

PC-PK1.1 数据层把升级设施做成独立类型：

```text
市场 31 -> 50 -> 51
农场 32 -> 52 -> 53
兵舍 33 -> 54 -> 55
锻冶 34 -> 56 -> 57
厩舍 35 -> 58 -> 59
```

因此底层不要只保存一个通用 `level` 而丢失原设施类型。市场/农场在合并建设中保留前一级收入，已由 C1/C2 的收入原函数直接确认。

## 3. 第九系技巧：内政系

PK 新增技巧ID 32～35：

1. **木牛流马（32）**：PC-PK1.1 `00496B48` 精确为输送移动力 +3。
2. **港关扩张（33）**：港关容量：
   - 金 10000 → 40000；
   - 粮 100000 → 400000；
   - 士兵 30000 → 60000；
   - 各兵装 30000 → 60000。
3. **政令整备（34）**：`0058D768 / 0058D776`；季初自然治安下降前精确 `ProbabilityCheck(50)`，命中则本次自然下降完全免除。
4. **人心掌握（35）**：D6 已恢复 `0058E510` 分支；`Random(0..2)>=1` 时跳过本次忠诚下降检查，即精确 **2/3** 免除，不再标“约67% empirical”。

费用仍使用各系第1～4级通用表：

```text
技巧P：1000 / 2000 / 3000 / 5000
金：   1000 / 2000 / 5000 / 10000
```

完整36技巧体系见 `22-techniques.md`。

## 4. 火攻系不是 PK 新增

重要纠错：无印已有火攻系四技巧：

- 木兽开发
- 神火计
- 火药炼成
- 爆药炼成

PK 继承并可能调整数值，但不能标成 PK 新系统。

## 5. 能力研究

`[PK]` 新增。完整规则已经拆到：

- `15-pk-ability-research.md`

已解决的关键点包括：

- 研究入口、300 金成本、20 行动力、无需技巧P。
- 一次只能研究一个节点。
- 培育武将消耗20行动力，通常30日。
- 五维低/中/高上限 70/80/95。
- 研究提升通常累计最多 +20，边界利用可到 +24；研究+经验总提升约 +30。
- 兵科/五维/特技各节点研究月数和使用次数。
- 10 个隐藏位置、候选隐藏特技及前置条件。
- 隐藏位置/特技在游戏开局时已决定，而不是研究到节点时再随机。

### “5 个还是 6 个隐藏特技”来源冲突

- 游民星空 2006 早期文章写“10个位置中最多6项”。
- 游民星空 2007 基于 San11Editor 的资料写**默认一个势力 5 个隐藏特技**。
- 日文攻略 Wiki 同样记录“10个候选位置中随机5个”，且称开局即确定。

因此 PC PK 默认按 **5 个隐藏特技位置** 实现，证据等级 `empirical-high`；旧“6项”资料保留在来源备注中，不作为默认规则。

## 6. PK 战场/设施差异

- 阵/砦/城塞等范围与效果相对无印存在调整。
- PK 中阵系还有异常状态恢复等增强。
- PK 部分设施造价与无印 PC 不同。

所有军事设施数据必须带 `version: vanilla|pk`，不要在一张无版本表里覆盖。

## 7. PK 难度/AI

PK 在超级难度与 AI 行为上存在差异；涉及经济倍率、委任、技巧研究时间等时，应通过 `rulesetVersion` + `difficulty` 双键取数据。


### 内政技巧概率说明

“政令整备”“人心掌握”都不是布尔永久免疫，而是在各自结算路径中做概率跳过。

- 政令整备：PC-PK 原函数精确50%。
- 人心掌握：`0058E510` 已逆向为 `Random(0..2)>=1` 跳过，即精确2/3。旧“约67% empirical”已撤回。
