# 战斗、战法、攻城、火焰、异常、伤亡

## 1. 部队面板

- 攻击受部队武力、兵种基础攻击、适性、技巧影响。
- 防御受部队统率、兵种基础防御、适性、技巧影响。
- 适性系数：S 1.0 / A 0.9 / B 0.8 / C 0.7。
- 剑兵无适性，按独立低系数。

现有 repo 的基础攻击/防御表继续作为数据源。

## 2. 普通攻击与反击

- 近接普通攻击通常遭反击。
- 弩等间接攻击通常不受反击。
- 兵器不能进行普通攻击/反击。
- 状态异常、技巧和特技可能禁用反击或让伤害无效。

## 3. 一齐攻击

- 多支相邻己军共同攻击一个目标。
- 发起部队承担反击。
- 总伤害并非简单等于所有部队普通攻击相加。
- 掎角等特技可附加混乱概率。

精确合击伤害函数仍需实测。

## 4. 战法

战法受：兵种、适性门槛、地形、气力、目标位置、技巧、特技影响。

典型气力：

- 枪：15 / 20 / 25
- 戟：15 / 20 / 30
- 弩：10 / 15 / 25
- 骑：15 / 20 / 25
- 兵器战法按兵器定义

战法成功后可发生位移、群攻、点燃、混乱、俘虏/战死附加机会等。

枪克骑、骑克戟、戟克枪；弩不在三角中。克制主要影响战法，不应直接套到普通攻击。

## 5. 暴击（会心）

- 由特技、能力比较、亲爱等因素触发。
- 提高战法伤害并可能强化附加效果。
- 螺旋突暴击可必定混乱；火矢暴击强化点燃。
- 现有 repo 采用伤害倍率 1.15；如未来找到更精确内部数据再替换。

## 6. 最终伤害

**这是当前最重要的未完全逆向区域之一。**

现有 repo 为了可运行采用：

`底数 = max(0,攻击-防御) × sqrt(兵力/1000)`

战法再叠加战法表数值、暴击和克制。

该式只能标为“临时采用”，不能声明为原版内部公式。

## 7. 攻城

城市/港关同时有：

- 驻兵
- 耐久

可通过削兵或削耐久攻陷。

- 冲车/木兽偏耐久伤害。
- 井阑/投石可有效杀伤城兵/设施。
- 云梯提高对据点/建筑伤害。
- 城兵或耐久归零均可导致陷落，具体接管后的剩余耐久/兵力需按实测表。

## 8. 军事设施

阵、砦、城塞、弓橹、连弩橹、太鼓台、军乐台、石兵八阵、投石台、土垒/石壁以及火罠等按现有 `docs/rules.md` 数据表实施。

版本差异：无印与 PK 的阵系范围/造价/异常恢复存在差别，数据结构必须带 `version`。

## 9. 火计与火罠

- 火计可点燃部队/设施/火球。
- 消火可灭火。
- 火球类沿方向滚动；火种类范围爆炸。
- 火焰可连锁点燃相邻火罠。
- 火神、藤甲、踏破、火攻相关技巧改变火伤/成功率。
- 火伤和计略伤害通常不按部队兵力线性增长。

火焰持续旬数、每旬地表火伤、不同爆药的精确伤害仍需保存为版本化数据表。

## 10. 异常状态

### 混乱

- 无法正常攻击/反击。
- 会乱跑。
- ZOC 消失。
- 敌方战法对其更容易/必中。
- 持续与恢复有概率机制。

### 伪报

- 部队自动朝所属据点撤退数旬。
- 无法正常反击；战法对其更容易/必中。

## 11. 击破后的武将结果

可能：

- 安全撤回/流落
- 负伤
- 战死
- 被俘

影响因素：战死设置、攻击种类、包围、捕缚、强运、血路、护卫、名马、戟兵等。

当前 repo 的百分比仅是实测近似，应进入版本化 RNG 表而不是写死为“官方公式”。
