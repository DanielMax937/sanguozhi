# 尚缺“精确内部公式”的规则与引擎采用策略

> 本文件不是“规则缺失清单”，而是“机制已经覆盖，但还没有足够证据声称精确复刻内部数值”的清单。

## A. P0：会显著改变整局模拟结果

### 1. 最终普通攻击/战法伤害公式

- 已知面板、适性、克制、暴击、战法表。
- 未知完整内部伤害函数、随机波动、地形修正。
- 当前 repo 的 sqrt(兵力/1000) 公式 = **临时采用**。

### 2. 行动力完整恢复公式

- 已知影响因素：君主统率/魅力、军师智力、城数、武将数、符节台。
- 缺精确封闭公式。

### 3. 征兵与兵装生产精确产量

- 魅力/政治修正、治安下降、特色赠送等还缺完整函数。

### 4. 登用概率

- 已知影响因素和必中/必败关系。
- “评分→成功率”未知。

### 5. 外交成功率

- 亲善、同盟、停战、劝降、俘虏交换的完整概率仍需实测。

### 6. 攻城伤害与陷落后资源继承

- 需要对耐久/驻兵两条路径做更多 save 对照。

### 7. 火焰持续、蔓延、地面火伤

- 不同技巧/特技/设施组合精确表仍需补齐。

### 8. 武将自然死亡/伤病恢复

- 已有寿命/年龄数据但缺完整 RNG 模型。

## B. P1：影响局部系统

- 混乱/伪报精确持续与清醒概率
- 单挑内部攻防/斗志/必杀公式
- 舌战每种牌的心理伤害点数
- 部队击破后的负伤/战死/俘虏概率
- 栈道/毒泉/落石精确伤害随机范围
- 军团委任 AI 的全部原作权重
- 君主继承精确优先级
- 评定完整提案表
- 遗迹/庙完整坐标与奖励

## C. 缺静态数据（不是公式问题）

1. 200×200 六角地图完整坐标/地形/高度/归属
2. 港关完整位置与所属城市
3. 堤防、水攻范围
4. 所有主剧本初始状态
5. 完整历史事件条件/效果
6. PK 能力研究完整树

## D. 引擎策略

每个不确定规则必须配置：

```json
{
  "evidence": "confirmed|empirical|provisional",
  "ruleset": "vanilla|pk",
  "source": ["..."],
  "value": "...",
  "notes": "..."
}
```

模拟报告必须能输出当前用了多少条 `provisional`，避免“跑得起来”被误解成“100% 原版精确”。
