# 征兵、兵装、编成、训练、补给与技巧

## 1. 征兵

前置：城市有兵舍。

影响因素：执行武将魅力/政治等、名声特技、城市容量、金、治安。

现有 repo 临时采用：`1000 + 政治×15`，300 金；魅力修正尚未知。该式不能标成原作已证实。

征兵会降低治安并增加技巧点/经验。

## 2. 兵装生产

- 枪、戟、弩：需要锻冶。
- 马：需要厩舍。
- 冲车/井阑等：需要工房。
- 楼船等：需要造船。
- 城市特色可降低相应造价并在月初自动赠送兵装。
- 能吏/繁殖等特技影响生产量。

## 3. 部队编成

- 主将 + 最多 2 副将。
- 带兵上限由主将官职/爵位相关指挥上限决定；军制改革再 +3000。
- 剑兵无需兵装。
- 枪/戟/弩/马按士兵数量消耗对应兵装。
- 攻城兵器/舰船按部队携带一件处理。
- 出征时可携金、粮；粮上限 50,000。

## 4. 部队能力合成

武力/统率等由主将与副将关系补正合成。

现有 repo 采用：

`主将 + (副将-主将)/关系系数`

夫妻/义兄弟=1，亲爱=2，其他=4；嫌恶可令副将补正失效。两个副将取更有利者。

兵种适性取队内该兵种最高适性。

## 5. 训练与气力

- 气力通常上限 100；熟练兵后 120。
- 城内训练提升气力；训练量受武将能力影响。
- 城/港/关内驻军可有自然气力恢复。
- 野外主要依赖军乐台、奏乐、昂扬等恢复。
- 军乐台范围内每旬 +10；奏乐每旬 +5，通常不与军乐台叠加，取更强效果。

## 6. 兵粮

每旬：

- 行军：士兵 / 10
- 输送：士兵 / 20
- 驻屯（含城内）：士兵 / 40
- 港/关驻屯且有屯田：0

部队粮尽后会出现大量逃兵；精确逃兵函数尚待锁定。

## 7. 补给与输送

- 输送队是地图单位，拥有独立移动力与容量。
- 可向城市/港关/部队运送兵、金、粮、兵装。
- 补兵后气力按旧兵与新兵人数加权平均。
- `[PK]` 木牛流马提高输送移动。

## 8. 技巧系统：无印已有 8 系

`[COMMON]`（PK 继承）

1. 枪兵系
2. 戟兵系
3. 弩兵系
4. 骑兵系
5. 练兵系
6. 发明系
7. 防御系
8. 火攻系

每系 4 级，必须从低到高研究。

成本：

- Lv1：1000 技巧P / 1000 金
- Lv2：2000 / 2000
- Lv3：3000 / 5000
- Lv4：5000 / 10000

研究时间受参与武将对应能力总和、难度、人才府（PK）等影响。

### 火攻系不是 PK 新增

无印资料已经明确存在木兽开发、神火计、火药炼成、爆药炼成。因此不得把“火攻系”标为 PK 专属。
