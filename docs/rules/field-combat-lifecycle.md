# O14：有限正兵力野战动作

日期：2026-10-18 UTC。profile：`o14-detached-positive-field-action-v1`。

这是独立、固定 episode 内的兵力 / 气力 / acted / 状态账本：一个主动动作批次，加至多一次合法主目标反应。它计算命中、会心、伤害与状态，全部受影响单位仍为正兵力才原子提交。它不是全战争、全旬推进、原生部队生命周期或完整原作指令结算。

## 4. 多目标与阶段顺序

`one-activation-primary-hit-v1` 固定一个主目标决定一次战法命中。横扫覆盖主方向 d、d-1、d+1；旋风覆盖 actor 六邻位。空格无效果，友军不受这两种戟战法伤害。完整占用由引擎枚举，调用者不能漏掉不利旁目标。

主目标先结算，其余按 cellId 排序；每个受影响敌单位独立判会心。主动伤害全部取行动开始快照，不能让前一个目标损失兵力后改变后一个目标的公式输入。这个命中批次、覆盖顺序与 RNG 顺序是明确的模拟政策，不认证 native collateral caller。

`primary-response-only-v1` 规定只有主目标在主动伤害及异常阶段后有一次反应资格；旁目标不反击。单条命令最多主动伤害批次加一次反应。连战、连击、支援、一齐、连环、反计等可触发上下文拒绝，不伪造 PC 连锁深度。

固定顺序：

1. 验证输入、完整上下文与资源；私有暂存费用和 acted
2. 战法 / 计略主命中；0 或 100 的确定结果不抽签
3. 按固定目标顺序处理：普通攻击盾 gate → 会心 → 伤害 → 本目标附加状态
4. 主目标反击 / 应射资格；只有合法反应才判急袭规避
5. 反应方盾 gate、会心和反向重算伤害
6. 全部单位正兵力及收据 / 保存预算核对后，一次提交

战法失败仍支付战法费用，只对主目标回落一次近接普攻。此时没有战法克制、溅射和螺旋状态，后续采用普通反击分支。失败不是无损空过。

## 5. 伤害与各层倍率

令 a / d 为本击攻方攻击 / 守方防御，N / M 为相应兵力；F 为 floor，T 为向零 trunc：

```text
U = (F(N*0.01)+300)*(a+50)^2*0.01
V = (F(M*0.01)+300)*(d+50)^2*0.01
R = T(U*100/(U+V)-50)+50
B = sqrt(k*64)
    + max(0,F((a^2-max(40,d)^2)/300))
    + max(0,F((N-M)/2000)) + 50
D = F((B*10*R*min(sqrt(F(N/4)),40)*0.000476190455*drum
       + F(N/200))*critical*matchup*tech*difficulty)
```

按 `binary64-source-formula-v1` 保留表达式顺序、括号和取整点，不另加随机伤害浮动；非有限中间值或安全数值域超界拒绝。原作 x87 精度、实际 PRNG、原 caller 和跨版本等价性仍 E。

- k=0 仍有其他加项，弩普通射击不是零伤害
- R 内负小数必须向零截断，不能换成 floor；d 的 40 下限只属于差平方项，V 使用真实 d
- critical 为 1 或 1.15，多个必会心技能不连乘
- matchup 是原来源变量 counter 的兵种相克项，不是反击倍率。只在主动成功战法应用：枪对骑 1.15 / 对戟 0.85；戟对枪 1.15 / 对骑 0.85；其余 1。普攻、失败回落普攻、反击和应射均为 1
- tech：对应锻炼 1.10；对应精锐 1.15 覆盖锻炼，不乘成 1.265。精锐面板 +10 与伤害层 1.15 分层，各自一次；此服务不再改 supplied 面板
- drum 固定 1，本域没有鼓台或 aura；实际存在设施的上下文不能按没有设施处理
- difficulty 由本击实际伤害者决定：normal=1、super-player=0.75。反击时重新取反应方难度，不能沿用原 actor

### 5.1 反击的独立模拟政策

`post-hit-reverse-core-counter-v1` 使用主目标受主动伤害及状态处理后的兵力和状态面板，交换攻守重算普通伤害；近接 k=10，弩应射 k=0，matchup=1。在完整 D 后再 floor(D*reactionScale)：普通 / 失败战法回落普攻的 scale=1；成功近接战法的 scale=1/2。

这两个 scale 和反应采样时点是本 profile 的模拟选择。来源仅支持“战法反伤通常较少”的定性认识，未恢复 clean-stock 反击闭式；不采用混有 MOD 背景的 40% 说法，也不把本次选择改称原作发现。

2026-10-18 补充核读 [Wiki 攻防研究](https://w.atwiki.jp/sangokushi11/pages/92.html) 的普通反击约 80–85% 实测描述，同样不足以恢复完整闭式及取样时点。本 profile 的反向重算后 scale=1 / 1/2 可以与这类实测比值不同，不能据此声称与原作反伤相同。

近接默认一次合法反击。间接普通射击只允许地上弩 profile、拥有技巧 9 应射、状态 normal 且可合法攻击原 actor 的主目标回应。应射复用当前范围与森林限制：距 3 的攻击源对无强弩应射方不可达；森林攻击源对无射手应射方不可打。双方都有应射也只一轮，不触发二次反应。

急袭：陆上原 actor 在已存在合法反应时 draw100<50 免除这一次反击伤害；可规避应射。它不是固定伤害乘 0.5，没有反应资格就不消耗急袭抽签。

## 6. 物理会心、盾与螺旋混乱

自然物理会心率：武力 <=60 加 0、61..79 加 1、>=80 加 2；C/B/A/S 加 0/1/2/3。每名副将喜爱主将 +2，夫妻或义兄弟 +4，嫌恶 -5；求和后 clip 到 0..100。同一主副将重叠关系类别拒绝，不猜优先级。

枪神 / 戟神匹配相应战法、斗神匹配枪戟战法、霸王匹配支持战法时，成功战法会心率为 100；重复命中规则仍只一次。枪将 / 戟将 / 勇将 / 神将 / 飞将 / 驱逐等条件物理会心技能不在本版支持表。

普通攻击、失败回落普攻、反击和应射采用 `normal-critical-reuse-tactic-rate-v1` 复用上述自然率。这是模拟选择；战法自然率来源不能证明普通攻击及反击原式。

`one-shield-gate-v1`：适用普通攻击来源时，戟矢盾对伤害者当前 weapon=crossbow 的普通伤害、大盾对所有普通伤害提供一次 30% 无效化。`crossbow-weapon-including-melee-v1` 因此包含弩兵 normal-melee 和弩兵近接反击，未仅按本击是否箭类判断；这是参照技巧 snapshot 的 crossbow normal/support 描述作出的明确模拟选择，不认证 stock 近接弩 caller。大盾覆盖矢盾，不能叠成 51% 或 60%。反击 / 应射是普通来源；成功战法不判盾，失败回落普攻可判。盾先于本击会心 / 伤害，被挡时伤害为零，不继续消费本击会心 roll；主目标仍可按固定政策取得反击资格。重叠与顺序同样为模拟政策。

螺旋成功后的混乱：

- 会心：直接 1+draw2，得到 1 或 2 count
- 非会心：先 draw100<30；未进入则无状态，进入后 draw2，0 表示无有效混乱，1 表示 1 count
- 此处不叠加普通计略 70/30 duration 抽签；洞察 / 沉着等计略免疫不自动挡物理眩晕
- 同击先用状态改变前的防御计算伤害，再写混乱；若目标随后混乱，就没有本命令反击

## 7. 扰乱与伪报状态

令 A智 / A魅为施计方 supplied 属性，B智 / B防为目标当时 supplied 属性。智力限 0..100，相关魅力 / 防御限 0..255。A智=B智=0 时分母为零，本 profile 拒绝，不补固定 50%。

C 为目标已异常时 10、否则 0；D 为 B智>A智 时 (B智-A智)/6、否则 0。命中性格 E 取目标主将：伪报胆小 3 / 冷静 1 / 刚胆 0 / 莽撞 -2；扰乱胆小 -2 / 冷静 0 / 刚胆 1 / 莽撞 3。

```text
伪报：
V1 = A智*0.3-B智*0.2+A魅*0.05+E+70+C
V2 = A智^2*(100-B智*0.9)*100/(A智^2+B智^2)/55
     -(100-A智)*0.1+A魅*0.05+E-D+C

扰乱：
V1 = A智*0.3-B智*0.2+B防*0.05+E+70+C
V2 = A智^2*(100-B智*0.9)*100/(A智^2+B智^2)/45
     -(100-A智)*0.1+B防*0.05+E-D+C
```

普通 rawRate=min(V1,V2)。`probability-floor-clip-v1` 先算完整分式，再在施计方有倾国且目标完整成员快照无女性时乘 2，然后 floor、clip0..100。0 / 100 不抽签，否则 draw100<p 成功；这套取整不认证原 callee。倾国不叠加，也不外推到落雷。

优先级为：完整合法性 → 洞察 / 条件看破 / 对应状态免疫 → 对应条件必中 → 普通公式及倾国。免疫先于必中；命中失败不判会心或 duration。

- 看破：目标中该技能 holder 的最大智力严格大于施计部队智力时看破
- 规律免疫伪报，沉着免疫扰乱，明镜免疫二者，洞察免疫二者
- 言毒对应伪报，机略对应扰乱，虚实对应二者；该技能 holder 的最大智力严格大于目标部队智力时必中
- holder 聚合采用 `resolved-skill-holder-max-intelligence-v1`：只在确实持有同一技能的成员中取最大智力。没有 holder 是缺席，不是能力 0；不把其他成员或全队面板智力冒作 holder 能力。这是替代未闭合 helper 的显式政策
- 神算的会心来源事实保留，但其防御复合语义及完整 getter / 优先级未冻结，因此是已知但未支持的计略技能，其可触发的计略上下文预检拒绝；不能仅实现必会心后忽略其余效果

### 7.1 普通计略会心

来源 listing `005AF520..005AF7E5` 在纯稳定 snapshot 子域支持：

```text
Q = A智 + E施计主将 - floor(B智/2)
ordinaryCriticalRate = max(3,trunc(Q/10))
```

会心性格修正使用施计主将：伪报胆小 10 / 冷静 5 / 刚胆 0 / 莽撞 -5；扰乱胆小 -5 / 冷静 0 / 刚胆 5 / 莽撞 10。不能混用命中公式的目标性格。

成功后深谋使会心率 100；妙计 holder 最大智力>B智，或确实存在的秘计 holder 最大智力<B智，也为 100。秘计缺席不能用 0 触发。listing 中神算存在即会心 100 的分支是来源事实，但本版计略上下文仍拒绝神算，不把来源事实当成支持范围。

来源的“上限 3”注释与跳转相反，实际为下限；`C1 FA 02` 为 SAR EDX,2，不是文本误写的 `sar dl,02`。这些是静态字节 / 控制流核读，不是实际运行反汇编或 clean-stock 身份认证。原 helper、二次性格读取时序、caller 和版本仍 E。

### 7.2 O01 状态语义 adapter

`o01-status-adapter-max-70-30-v1` 是内部 adapter，沿用 O01 的 normal / confused / false-report 与 remaining 语义：

- 普通计略成功后 draw100<70 得 base1，否则 base2；会心再 +1。70/30 是模拟分布，不是原作恢复结果
- 原 normal 直接应用；同类异常剩余 count 取 max(old,rolledDuration)，不是累加
- 异类异常替换拒绝整个命令，兵力、气力、acted、RNG、revision 都不提交
- 螺旋已算出的 count 直接走状态应用 / max 部分，不再走普通 duration 分布
- 收据保留 old / rolled / requested / actual / after；旧 3、新 1 时 actual delta=0，不能说延长 1

已知目标当前处于另一种异常时，在抽签前拒绝结构上不支持的替换；不能靠可能 miss、免疫或非会心螺旋可能得到零 count 绕过这条域边界。

O01 公开 applyStatus 接口接受“已成功”效果；本服务不把这种接口暴露为可绕过命中计算的命令。它只在 reducer 已计算成功 / 会心后内部适配，没有导入完整旬调度。

false-report-status 保留位置，只设置异常；不写 native 任务，不声称目标已经撤退。后续需要自动撤退的状态推进仍属于域外，不能提前改 acted、伪造 home/path 或另起 episode 来冒充已完成原作撤退。

## 8. 支持事实与预检拒绝

本版支持执行的 20 种技能精确为：急袭、射手、枪神、戟神、斗神、霸王、洞察、看破、规律、沉着、明镜、言毒、机略、虚实、深谋、妙计、秘计、百出、鬼谋、倾国。另识别 16 种未支持物理技能与 3 种未支持计略技能，保留其完整事实并在相关动作域预检拒绝。其他未知技能在 create 拒绝，不能靠 caller 隐去一部分技能取得许可。相同技能可有多个 holder，但只能按规定聚合 / 生效一次。

- 百出将普通计略费用设为 1，不叠加折扣；鬼谋射程仅 +1；倾国仅按 §7 乘一次
- 技巧锻炼 / 精锐按 §5 分层，熟练兵仅服务 energyCap，不能冒作伤害 1.10

## 9. 原子性、RNG 与全收据

每次命令使用私有状态及 RNG cursor 暂存。任何主目标、旁目标或反应使 troops<=0，返回 `unsupported-terminal-effect`，before=after、effects 为空，气力 / acted / 状态 / RNG cursor / revision 全部原样。不能夹为 1，不能先提交主目标再拒绝旁目标。建筑 / 设施没有 HP writer，其目标在预检即拒绝；这不关闭耐久或城陷证据。

RNG tape 项为 `{stage,bound,value}`，value 是 0..bound-1 的整数。只有实际非确定分支消费；命中 / 会心 / 盾 / 急袭用 draw100，螺旋 count 用 draw2，普通计略 duration 用 draw100。stage、bound 和 cursor 必须匹配；耗尽、错 stage 或错 bound 全命令回滚。tape 是可重放输入，不认证原 global PRNG 及其相关性。

preview 与 execute 使用同一个 reducer，preview 不消费外部随机数或改调用者对象。同 commandId、同 payload 返回历史原 receipt，且不再扣费 / 抽签；同 ID 异 payload 冲突拒绝，新 ID 旧 revision 拒绝。历史中所有已保存命令的幂等收据均保留，不能仅记最后一条。

收据完整包含：命令、schema / profile 版本与 policy 内容 hash、episode、前后 revision / state hash、actor / target 身份与 side、开始格 / 发动格、合法性及覆盖排序、逐阶段来源 / 证据等级 / policy、面板选择、命中和会心公式中间值 / 优先级、各倍率来源、每条 RNG、确定不抽签原因、反击资格 / 盾 / 规避理由、逐字段前后值和请求 / 实际差额。完整 policy snapshot 在 state 和 genesis.scenario 中保留并核对，不仅保存其 hash。主动和反应分开，matchup 和 reactionScale 分开。失败不能把 tentative 元数据写成已提交 effects。

## 10. 保存、加载与停止边界

保存完整 genesis、固定地图、成员 / 技巧 / 面板事实、policy snapshot、完整 RNG tape、命令历史、逐阶段 receipts 与最终 snapshot。DTO 为非 Proxy、未污染运行环境中的封闭普通 JSON 结构；未知字段、非预期原型 / accessor、非有限数值、超出数量 / 深度 / 字节预算等拒绝，不靠丢弃未知字段修复。反射可能触发 Proxy traps，不声称防护任意恶意 Proxy。具体字段和预算见引擎说明。

load / replay 从 genesis 独立执行全部历史，比较完整 receipt 和最终状态；不能只比兵数、终态 hash 或某几个效果。FNV-1a64 / UTF-16 hash 只是非认证内容标签，不证明来源，也不能抵抗同时改写 genesis 和所有可自洽结果的行为。policy 任意字段、holder 能力、反应 scale、RNG stage、旁目标顺序、概率中间值或 count 实际差额与 genesis 回算不一致时，不能靠最终兵数巧合相同蒙混。预算不足必须在命令提交前原子拒绝，不能产生无法保存的已接受历史；超过预算不静默裁去旧 receipt。

本版没有火计、落雷、火矢、贯射、乱射、骑射、骑兵战法、位移 / 碰撞、攻城、建筑 HP、击破、捕获、死亡或其他终局处置。落雷只有命中式不足以执行中心及六邻格、友伤、设施伤害和点火，故不列合法命令。
