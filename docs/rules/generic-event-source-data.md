# 所选通用事件公开攻略转录

状态：`public-guide-transcription`，`executionEnabled: false`。这是独立静态资料批，未加入事件求值器、scheduler、结果执行器或引擎依赖，未运行原游戏native。

[Wiki88通用段](https://w.atwiki.jp/sangokushi11/pages/88.html)全部31标题，加[游民2009加强版攻略首页铜雀补记](https://www.gamersky.com/handbook/200902/134257.shtml)及[第13页泰山封禅](https://www.gamersky.com/handbook/200902/134257_13.shtml)，得到33条来源观测、31个新`generic.*`资料ID。独立目录和说明见[`data/generic-events`](../../data/generic-events/README.md)。旧史实目录保持105/66/41及全部原文件字节。

31个Wiki标题的覆盖质量分别是：6段较实质条件/结果、2段仅条件、1段明确未验证的文官推举轶闻、1段赞赏定性结果、21段仅标题。仅标题条目不填规则；文官推举不把局面轶闻变为必要条件。两条游民观测单列，不混入这31的分类分母。

每条保留来源URL、节名、所选范围内序号、web工具行号、当次文本快照hash及未知原生ID/flag/概率。数值来源未给时为null，条件缺失不是否定或无条件触发。快照是web工具渲染文本，非原始HTML；工具显示抓取缓存年龄，不能声明源站实时新鲜度。原始工具结果和三份选段快照在可恢复审阅包中；本库只固定hash与边界，校验器可显式传入快照目录复验。

10项来源比较/解释问题仍未决，包括铜雀爵位与字面“邻”、省略条件/取得后说明、泰山徐州一城对小沛、能力数值/兵种经验对定性适性、带问号的部下功绩、于吉选项XP范围以及来源版本/独立性。五虎初旬不改成1日，猜测经验量不数值化。Wiki未指明版本；游民写加强版，但平台、补丁未知，不能宣称独立同版互证。

本批仅完成“所选公开攻略段转录”。完整游戏通用类别、21空标题缺失内容、未决差异、PS2独立资料、原作目录、历史开关行为与精确运行时条件/结果仍缺；下一证据是可归属版本的补充资料和原始事件表/flag/caller。本批不触碰P0-78及依赖capture、势力消亡、native事务的受限工作。
