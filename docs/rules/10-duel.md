# 单挑（一骑讨）

## 1. 进入条件

- 相邻敌我部队可发起单挑。
- 对方可接受/拒绝；混乱、太鼓台、武将性格/武力等影响应战倾向。
- 部队中主将/副将均可能参与或换人。

## 2. 胜负

- 双方以“体力”为核心 HP。
- 一方体力先归零则败。
- 50 回合仍未决出胜负则平局。
- 一方成功撤退则另一方获胜。

## 3. 战斗方针

原作存在多种自动战斗方针，至少包括：

- 攻击重视
- 防御重视
- 斗志重视
- 一击/必杀相关方针

武将会按方针自动攻击并积累斗志。

## 4. 斗志与必杀

- 斗志达到阈值可发动要害、必杀、无双等动作（名称/条件按平台数据表）。
- 剑类宝物提高斗志获得。
- 长柄武器提高攻击表现。
- 暗器等宝物可提供特殊攻击。

## 5. 援助/换人

- 同部队其他武将可加入/替换。
- 嫌恶关系不会前来援助。
- 配偶/义兄弟/亲爱关系影响援助倾向。

## 6. 俘虏与撤退

- 胜利后可能俘虏败将。
- 名马使撤退必定成功并规避被俘。
- 捕缚等特技影响俘虏。
- 主机版/家用机存在俘虏率差异，必须按平台配置。

## 7. 对部队的外部效果

- 单挑胜负会改变双方部队气力。
- 武将可能负伤/被俘。
- 若某部队仅剩的武将被俘，部队直接消失。

## 8. 精确数值状态

目前公开资料能确认机制，但**攻击、防御、命中、斗志增长、各必杀伤害的完整内部公式尚未在 repo 中锁定**。

引擎第一阶段可：

- 用武力差驱动命中/伤害
- 用方针修正攻击/防御/斗志
- 保持 50 回合上限

但必须标为 `duelModel=v0-provisional`，禁止声称为原版公式。
