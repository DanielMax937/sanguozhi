# 通用事件、历史事件、遗迹与庙

## 1. 事件引擎

每个事件必须包含：

- 版本
- 可触发剧本/日期范围
- 势力条件
- 城市条件
- 武将状态/所在条件
- 外交条件
- 历史事件开关
- 一次性标记
- 效果列表

禁止把历史事件硬编码在 UI。

## 2. 已知历史事件类别

公开攻略已记录的例子：

- 娶大小二乔
- 诸葛亮娶妻
- 张松献图
- 汉中王
- 五虎将
- 三顾茅庐等

这些事件的条件必须逐条对照游戏/攻略数据后录入 `scenario-events.json`，不能仅凭演义常识推导。

## 3. 通用人物事件

应覆盖：

- 义兄弟相关事件
- 夫妻援助
- 人才推荐
- 军师/武将提案
- 评定
- 官爵授予
- 武将登场/隐退/死亡
- 宝物/铜雀等发现

## 4. 评定

现有 repo 只记录“评定 +10 技巧点”，但完整系统还必须定义：

- 触发时机
- 哪些武将可提出意见
- 玩家/AI 选择
- 接受后产生的实际政务/外交/军事效果

在没有原作完整提案表之前，可先把评定作为事件接口保留，不应发明额外加成。

## 5. 遗迹与庙

- 地图上存在隐藏遗迹/庙位置。
- 探索/部队经过满足条件时可发现。
- 可给予能力/特技相关奖励；发现会给魅力经验。
- 位置与奖励表需要作为地图静态数据单独导入。

## 6. 历史事件与沙盒

游戏设置“历史事件关闭”时：

- 关闭会强制改变势力/人物状态的历史剧情。
- 普通系统事件（死亡、灾害、爵位等）继续运行。
