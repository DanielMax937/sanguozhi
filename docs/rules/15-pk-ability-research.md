# PK 能力研究与武将培育

> `[PK]` 专属。无印没有能力研究系统。

## 1. 研究命令

`[PK][confirmed/empirical-high]`

在城市、关、港均可执行“君主 → 能力研究”。

执行条件：

- 金 ≥300
- 行动力 ≥20

每研究一个节点：

- 消耗 300 金
- 消耗 20 行动力
- **不消耗技巧点**
- 同一时间只能研究 1 个项目
- 研究耗时由节点决定（3/4/5/6个月等）

来源（游民星空）：https://www.gamersky.com/handbook/200707/69811.shtml

## 2. 培育武将

研究完成后使用“培育武将”：

- 每次消耗 20 行动力
- 一名武将一次只能学习一个项目
- 五维强化、兵科适性、特技为三类独立培育类别
- 同一旬理论上最多可让三名不同武将分别进行这三类培育
- 单次培育通常需要 30 日

来源：
- https://www.gamersky.com/handbook/200707/69811.shtml
- https://game.zol.com.cn/228/2285144.html

## 3. 五维强化上限

`[PK][empirical-high]`

- ○+低：最多把该能力提高到 70
- ○+中：最多到 80
- ○+高：最多到 95
- 研究培育带来的累计能力提升原则上限 +20
- 因“撞上档位上限”导致最后一次实际提升不足时，可利用边界把研究提升做到最高约 +24
- 能力研究 + 正常经验成长合计最多可比初始能力高约 30

例：初始51，低级强化4次到70，只实际 +19，因此还能再用一次中级强化到75。

来源：https://w.atwiki.jp/sangokushi11/pages/46.html

## 4. 使用次数

| 项目 | 全势力可使用次数 |
|---|---:|
| 各五维 +5低 | 5 |
| 各五维 +5中 | 5 |

## 5. 一般节点研究时间

公开整理：

### 兵科适性
- B级：4个月，5次
- A级：5个月，5次

### 五维 +5
- 低：3个月，5次
- 中：4个月，5次
- 高：6个月，3次

### 常见基础特技
- 3个月：运搬、扫讨、不屈、金刚、铁壁、待伏、筑城等
- 4个月：射程、发明等
- 6个月：捕缚、连战、辅佐、霸王、深谋、明镜、名声、能吏、繁殖等
- 强力特技的可培育次数更少（如霸王/捕缚/深谋为1）

## 6. 隐藏特技位置

游戏开始时，从 10 个隐藏位置中随机决定若干隐藏特技位置；攻略 Wiki/官方攻略信息主要支持**5 个位置**在开局时被确定。

这些结果在开局时已经固定，不是在研究到该节点时临时抽取。

### 位置1：武力系
- 心攻：骑兵B
- 枪神：连战 + 枪兵B
- 戟神 / 弓神 / 水神：连战 + 弩兵B

### 位置2：统率系
- 长驱 / 踏破：金刚
- 血路：统+5低
- 护卫：不屈
- 奏乐：不屈 + 辅佐

### 位置3：政治系
- 指导 / 眼力：不屈 + 筑城
- 征税：繁殖
- 风水 / 祈愿：筑城

### 位置4：知力系A
- 看破 / 连环：魅+5低 + 待伏
- 火神：知+5中
- 鬼谋：知+5低 + 明镜
- 反计：知+5低 + 待伏

### 位置5：武力系高阶
- 乱战 / 勇将：枪兵A
- 掎角 / 斗神：连战
- 疾走：武+5高

### 位置6：兵器系高阶
- 攻城 / 神将：知+5高 + 兵器A
- 骑神 / 工神 / 猛者：兵器A

### 位置7：统率系高阶
- 飞将：统+5高 + 霸王
- 遁走 / 强运：统+5中
- 强行 / 藤甲：统+5高

### 位置8：政治系收入
- 米道：发明 或 政+5高
- 征收：发明、政+5高，或二者组合（候选依开局隐藏项）

### 位置9：政治系辅助
- 屯田：造船 / 发明 / 二者组合
- 仁政：造船 或 发明

### 位置10：知力系高阶
- 虚实 / 洞察 / 百出 / 鬼门：知+5高
- 神算：深谋

## 7. 不能通过能力研究学习的特技

能力研究并不覆盖全部100特技。一批特技只能由武将原生、庙等渠道取得，例如推进、操舵、解毒、威风、昂扬、火攻、言毒、机略、诡计、妙计、秘计、倾国、妖术、规律、沉着、诗想、富豪、亲乌/羌/越/蛮、内助等。

因此数据模型必须区分：

`skill.learnableByAbilityResearch`

## 9. 来源冲突与未实现边界

以下差异保留在数据 `conflicts`，没有通过猜测消除：

1. 原图知ロ缺少魅+5低箭头，但 Wiki 表与 ZOL 路径都要求看破/连环为魅+5低 AND 待伏。语义候选采用表格，原图箭头清单保留实际29条。
2. 心攻的 ZOL 明列6个月，原图武ロ槽位写3个月，图并未逐候选列时长。Wiki链接的编辑器截图第48行直接显示3个月，故攻略数据取3并保留ZOL的6；不是从槽位默认猜值。
3. 祈愿（Wiki祈願；ZOL祈祷）使用次数 Wiki为5、ZOL为3，Wiki链接的编辑器截图第62行也显示5，故攻略数据取5并保留ZOL差异。
4. ZOL开头写最多6个隐藏项、后文写5个；Wiki及游民星空支持5。保留攻略默认5，但没有实现抽取或随机流。
5. 戟兵B原图由武+5低指入；游民星空旧文说统+5低。本次基础树忠实记录原图的武+5低，并保留旧文差异，不能据此声称clean-stock原生前置已认证。
6. Wiki政治ロ第三列明确有“仅发明→征收”候选，ZOL路径摘要未列这一项。数据保留Wiki全表，不把摘要当作穷举。
