# 舌战攻击方选择独立核 v1

本页规定 `debate-attacker-selection-reference-v1`：在调用方给定的两方检查点上，静态对应现代参考的 `GetCardPower` 与 `CalcAttacker`，计算基础牌力、应用刚胆正计时替换，再严格比较两方最终牌力。入口为 `evaluateDebateAttackerSelection`。

[API 合同与精确 DTO](../engine/debate-attacker-selection-v1.md) · [政策与固定来源记录](../sources/debate-attacker-selection-v1.json)。本文只陈述规则与人工推导，不是候选核运行记录、测试通过证明或完整舌战实现。

## 2. 输入合同与有界检查点

输入必须显式携带下列字段，不默认补政策，不迁移其他 profile：

| 字段 | 支持域 |
| --- | --- |
| `schemaVersion` | 严格为1 |
| `profile` | `debate-attacker-selection-reference-v1` |
| `policies` | 与完整导出常量 `DEBATE_ATTACKER_SELECTION_POLICY_V1` 完全一致；政策 id 为 `debate-attacker-selection-policy-v1`，仅给 id 不够 |
| `currentTopic` | 有符号32位整数，含0..2之外的值 |
| `characters` | 恰好两项，固定对应队伍0、1 |
| `playedCards` | 恰好两项有符号32位整数，固定对应队伍0、1 |

每个 `characters` 元素仅包含：

- `personality`：`timid`、`calm`、`bold`、`reckless`，分别是胆小、冷静、刚胆、莽撞的已解析性格。
- `angerTimer`：整数0..4。

这里的 `personality` 已经是调用方解析后的结果，不接收人物、人物ID、性格覆盖字段或 getter，也不重现来源的覆盖／回落过程。timer 限为0..4是本 profile 的工程支持域；来源的攻击方方法只判断 `> 0`，不能把拒绝 timer=5 说成来源禁止该值。

有符号32位范围为−2147483648..2147483647。范围内的整数牌号即使不是0..14中的牌，仍是合法计算输入；基础牌力为0，不因未知牌号直接拒绝。范围内的整数话题即使不是0、1、2，也仍是合法输入，只是不享有普通牌匹配加10。

相反，超出有符号32位范围的牌号／话题、字符串、非整数、负零、NaN、Infinity、未知性格、域外 timer、缺失／额外字段、错误数组长度或不匹配政策属于输入／支持域错误，不能伪装为来源的0牌力或平局。精确错误名、校验先后和资源边界以API合同为准；这里不推定错误收据字段。

该输入是一个可独立询问的合成检查点，不要求证明它从新局合法可达。`playedCards` 的命名不证明这些牌已经合法选择、存在于手牌或允许在该状态使用。

## 3. 基础牌力：先按牌号分支

对两方分别计算基础牌力，使用同一个输入 `currentTopic`，不先更新话题。

| 牌号 | 牌类 | 基础牌力 |
| --- | --- | --- |
| 12 | 无视 Ignore | 120 |
| 10 | 大喝 Shout | 110 |
| 11 | 诡辩 Sophistry | 20 |
| 1..9 | 普通话题牌 | `1 + 零基等级 + 匹配加成` |
| 其他有符号32位整数 | 再考0、镇静13、激昂14及未知／范围外牌号 | 0 |

普通话题牌的完整映射：

| 牌号 | 牌话题 | 零基等级 | 不匹配或输入话题无效 | 输入话题有效且匹配 |
| --- | --- | --- | --- | --- |
| 1 | 故事0 | 0 | 1 | 11 |
| 2 | 故事0 | 1 | 2 | 12 |
| 3 | 故事0 | 2 | 3 | 13 |
| 4 | 道理1 | 0 | 1 | 11 |
| 5 | 道理1 | 1 | 2 | 12 |
| 6 | 道理1 | 2 | 3 | 13 |
| 7 | 时节2 | 0 | 1 | 11 |
| 8 | 时节2 | 1 | 2 | 12 |
| 9 | 时节2 | 2 | 3 | 13 |

匹配加成严格是：输入话题在0..2内，并且与牌话题相等时加10，否则加0。两个条件缺一不可；不能只比较 helper 返回值。例如输入话题−1、未知牌−1时，不能因为 helper 的无效哨兵同为−1就给该牌加10。未知牌也根本不进入普通牌公式。

无视、大喝、诡辩在普通牌分支之前直接返回其固定基础牌力，不检查话题有效性，不叠加匹配加10。镇静、激昂与再考在这个方法中只是基础牌力0；这不等于它们没有其他效果，也不决定其可用性。

无刚胆替换时，基础牌力优先级为：无视120 > 大喝110 > 诡辩20 > 匹配普通牌11..13 > 不匹配普通牌1..3 > 其余0。同一普通牌组中大／中／小严格递减；不同非当前话题的同等级普通牌可以同力。

## 4. 刚胆正计时：无条件赋值100

基础牌力计算完成后，对每一方独立检查：

`angerTimer > 0 && personality == 'bold'`

条件成立时，将该方最终牌力直接替换为100；否则最终牌力等于基础牌力。这不是加100、不是乘法、不是至少100、不是与100取最大值，也不以普通牌为前提。

| 性格／timer | 最终牌力 |
| --- | --- |
| bold，timer=1..4 | 恒100，无论基础牌力多少 |
| bold，timer=0 | 保留基础牌力 |
| timid、calm、reckless，timer=0..4 | 保留基础牌力 |

因此该分支可以把无视120降到100、大喝110降到100；把诡辩20、任意普通牌以及基础牌力0的牌提高到100。0、13、14与未知牌号都不能跳过刚胆覆盖：合法输入中的牌号−2147483648或2147483647同样可以得到最终牌力100。

两方的替换各自独立，不存在先处理0方就不处理1方的短路，也不看对方性格。双方刚胆正 timer 时，二者最终牌力都为100，原始牌类和timer的具体正值不再打破平局。胆小、冷静、莽撞即使有正timer，也不会在本方法得到替换。

这不同于卡牌可用性核中将冷静／刚胆正timer归入局部受限状态的判定。不能复用那个局部布尔值，误把冷静正timer也改为100。

## 5. 严格比较与结果边界

来源顺序为：计算0方基础牌力 → 计算1方基础牌力 → 必要时替换0方牌力 → 必要时替换1方牌力 → 将攻击方初始化为−1 → 比较。

- 0方最终牌力严格大于1方，攻击方为0。
- 否则，1方最终牌力严格大于0方，攻击方为1。
- 两方相等，攻击方保留−1。

平局不按先手、队伍0优先、挑战者、性格、timer大小、牌号高低或随机数打破。结果中的0、1始终是数组队伍下标；−1表示此比较未产生攻击方，不表示输入错误，也不是战斗终局胜者。

选择攻击方不等于执行攻击。此核不把牌力差当伤害，不计算任何HP、压力、伤害系数或实际变化；不更新先手、话题、timer、手牌、轮次或持久状态；不调用随机源。来源 `CalcAttacker` 对对象字段 `attacker` 的写入在独立核中表现为返回计算结果，不意味着对调用方状态执行同名写入。

## 6. 与卡牌可用性严格分离

本核不调用 `evaluateDebateCardAvailability` 或来源 `IsCardAvailable`，也没有隐式可用性前置门槛。正常输入的成功计算不证明合法出牌：

1. 刚胆正timer持无视／大喝，是展示无条件100替换的重要合成案例，即使上游可用性规则可能禁止该角色选择话术，也不能在本核悄悄过滤，或改回120／110。
2. 对手冷静正timer可能影响另一核的话术可用性，但不改变此核的 `GetCardPower`，也不会在此核直接产生阻断。
3. 牌号15或有符号32位端点在可用性查询中不可用，在此核仍可作为合法整数得到基础0，再接受适用的刚胆覆盖。两核回答不同问题，不构成冲突。
4. 再考0、镇静13、激昂14的基础0不认证它们可被作为本轮攻击牌选择，更不执行其效果。

真正串联选牌、消费、攻击与效果的流程，需要另行定义可达状态和编排合同。不能把一组独立查询成功拼成完整会话已通过验证。

另需区别纸面输入边界：

- 牌号／话题为2147483648或−2147483649时超出本核支持域，不能截断成32位后继续算；`"12"`也不能隐式转换为数字12。
