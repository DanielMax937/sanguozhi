# 汉帝、爵位、君主继承、军团、势力灭亡与统一

## 1. 爵位

爵位由势力城市数等条件决定；汉室存在时通常由汉室授予，特定条件可自称。

已核对城数门槛：

- 无：1 城
- 州刺史：2 城
- 州牧：4 城
- 羽林中郎将：6 城
- 五官中郎将：8 城
- 大将军：12 城
- 大司马：14 城
- 公：18 城
- 王：20 城
- 皇帝：24 城，且满足汉帝拥立/不存在等条件

月初且君主未行动时会触发授爵/自称相关事件。

黄巾势力有特殊规则：没有通常爵位/官职体系，并具有特殊带兵上限。

## 2. 官职

- 爵位决定可授官职范围。
- 功绩决定武将可任官职。
- 官职提供指挥兵力和能力加成，并产生俸禄。
- 官职升降本身不改变忠诚。

## 3. 汉帝

游戏状态必须保存：

- 汉帝是否存在
- 所在城市/控制势力
- 是否被拥立

占领汉帝所在城市后应触发拥立/废立等政治事件；不同选择影响汉室态度武将、爵位/称帝路径和历史事件。

当前 repo 尚无完整拥立/废立数值后果，需继续从事件数据/实测补齐；但状态机必须预留。

## 4. 君主继承

君主死亡/被处斩/特定事件退出后：

1. 从势力武将中选择继任者（血缘、身份、能力、功绩等优先）。
2. 更新君主关系与军师/太守/都督。
3. 对全势力武将忠诚进行继位影响结算。
4. 若无合法继承者，势力灭亡/并入按事件处理。

精确继承优先级需从剧本实测继续锁定，当前不得随机挑选。

## 5. 军团 / 委任

### 数据模型

军团至少包含：

- 都督
- 所属城市/港关
- 攻略目标/方针
- 允许的内政、生产、出征类型
- 军团行动力

### 委任行为

COM 委任会自行：

- 建设内政设施
- 巡查、征兵、训练
- 生产兵装/兵器
- 搜索/登用
- 调动武将
- 根据方针出征

可靠攻略显示委任内政通常试图为每城至少保有：兵舍、锻冶、市场×3、农场×3，并会为了满足目标拆除其他设施。

### 引擎实现原则

委任必须由同一个合法命令枚举器驱动，不允许 AI 绕过玩家规则免费生产。

## 6. 势力灭亡

当势力失去最后据点：

- 君主及城内武将进入俘虏/在野/被登用等结算。
- 在外部队的去向按原作规则处理（消失/转在野/归附近据点等需实测数据）。
- 城市、金粮、兵装按攻陷接管规则转移。
- 外交关系清除。

## 7. 统一判定

玩家/AI 势力控制全部有效城市并消灭其他势力后进入统一结局。

历史结局文本不影响规则引擎；引擎只需产出 `GameWon` / `ChinaUnified` 事件。
