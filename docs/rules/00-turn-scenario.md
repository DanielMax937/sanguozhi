# 时间、回合、难度与剧本

## 1. 时间单位

- `[COMMON][已证实]` 1 回合（旬）= 10 日；每月 3 旬：1日、11日、21日。
- `[COMMON][已证实]` 每月 1 日结算金收入。
- `[COMMON][已证实]` 1、4、7、10 月 1 日结算粮收入。
- `[COMMON][已证实]` 兵粮消耗每旬结算一次。
- 建设、技巧研究、伤病、事件、武将登场等都以日/旬推进。

## 2. 一旬的推荐引擎结算顺序

> 原作内部所有同帧细节未完全公开；以下按可观察结果建立确定顺序。

1. 日期推进至本旬。
2. 月初/季初资源收入。
3. 行动力恢复。
4. 建设/吸收合并/技巧研究进度。
5. 港关/据点耐久恢复。
6. 武将登场、自然死亡、伤病恢复、俘虏忠诚变化。
7. 忠诚/俸禄等月度或季度结算。
8. 灾害、丰收、贼/异族等世界事件。
9. 按势力行动顺序逐个势力行动。
10. 本旬结束：行军兵粮、持续火焰/地形伤害、异常恢复等持续效果。
11. 势力灭亡/继承/统一判定。

## 3. 势力行动顺序

- `[COMMON][实测可信]` 行动顺序会动态变化，不固定为剧本势力列表顺序。
- 玩家实测表明，**爵位与都市数是主要排序键，同条件下武将数会进一步影响顺序**。
- 可观察到较强/规模更大的势力往往后行动；取得爵位、增减城市或武将后，可能在相邻两旬出现连续行动/连续被行动的现象。

### 引擎采用

排序键按以下顺序从“小/低”到“大/高”，较小者先行动：

1. 爵位等级
2. 支配都市数
3. 所属武将数
4. 势力 ID（稳定 tie-break，保证确定性）

> `临时采用`：第 1–3 项来源于实测；确切比较优先级仍应继续做 save 实测。不要写入“确定规则”。

## 4. 难度

### 初级

- `[COMMON][已证实]` 玩家经济收入相对上级约 +25%。
- 外交论客触发舌战成功进入率高（常见资料按初级/上级 100%）。

### 上级

- 作为城市基础收入、城市数据对照的默认难度。

### 超级

- `[COMMON][已证实/实测]` 玩家收入相对上级约 -25%，COM 经济有加成；从玩家视角 COM 与玩家资源倍率差显著扩大。
- `[COMMON][实测可信]` 论客外交被接受进入舌战的概率约 20%。
- 技巧研究时间与其他难度不同。

## 5. 剧本初始化

每个可运行剧本必须完整定义：

- 日期（年/月/旬）
- 所有势力及君主
- 爵位、军师、技巧点、已研究技巧
- 支配城市、港、关
- 城市金/粮/兵/气力/治安/耐久/兵装/兵器/舰船
- 内政设施及等级（PK）
- 武将状态：所属、身份、所在、忠诚、功绩、官职、健康、是否已发现
- 宝物持有人/所在地
- 势力外交友好度、同盟/停战期限
- 汉帝是否存在及所在地
- 地图上的部队/建筑/火焰状态（若剧本需要）
- 历史事件开关

当前 repo 仅有武将/城市等基础表，**各主剧本完整初始状态仍需单独数据化**。
