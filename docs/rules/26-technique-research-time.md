# E11 技巧研究时间

更新：2026-09-30。主目标版本：PC-PK1.1；难度分档目前只对“超级”有明确实测。

## 1. 撤回 E7 的过度泛化

E7 曾把“相关能力和210 -> Lv1~4 为30/40/60/90日”写得过于像所有技巧的统一公式。

E11 重新核对后必须收窄：

- 日文 Wiki 2021 实测确认超级存在 70 / 140 / 210 / 280 四个相关能力和分档；
- 同一评论给出能力和210、无人才府时30/40/60/90日；
- 但没有注明测试的具体技巧系；
- 早期攻略明确说明研究时间不是固定值，而且不同技巧系“通常显示时间”本身分成两组。

所以 30/40/60/90 只是已观测锚点，不能覆盖全部36项技巧。

## 2. 三名研究武将的相关能力和会改变研究时间

## 3. 超级难度已知锚点

### 3.1 能力和210，无人才府

Wiki 实测：

```text
Lv1 30日
Lv2 40日
Lv3 60日
Lv4 90日
```

但因为测试技巧系未注明，这组不能全局化。

### 3.2 人才府与210/280

实测：

```text
210 + 人才府：Lv1 = 10日
280 + 人才府：Lv1 = 10日
280 + 人才府：Lv4 = 60日
```

## 4. 人才府是源码级精确 -20日，最低10日

PC-PK1.1 地址：

```text
005D7ED7  人才府对技巧研究减20天
005D7EF0  耗时下限1
005D7EF4  低于下限时保底1
```

以旬为单位：

```ts
finalTurns = max(1, baseTurns - 2)
finalDays = finalTurns * 10
```

所以人才府不是百分比减时，也不是减半。

结合“280 + 人才府 Lv4 = 60日”，可以严格反推出同一测试条件无人才府 Lv4 = 80日。

## 5. 攻略层存在两组通常显示时间

早期攻略明确写：技巧研究时间不固定，下面只是一般显示值。

### 5.1 枪/戟/弩/骑/练兵

```text
30 / 40 / 60 / 90日
```

### 5.2 发明/防卫/火攻/PK内政

```text
40 / 50 / 70 / 100日
```

这说明不能只用 level + abilitySum 两个变量武断补全公式；技巧本身或技巧系还存在基础时长类别。

究竟是结构体隐藏字段、技巧ID分支还是其他数据，目前 open。

## 6. 不允许用现有锚点插值补完整矩阵

虽然已知某测试序列：

```text
能力和210 Lv4 = 90
能力和280 Lv4 = 80
```

也不能据此直接猜：

```text
140 -> 100
70 -> 110
<70 -> 120
```

更不能假定 Lv1~Lv3 每跨70也固定减10。

没有证据就保留未知格。

## 7. 初级/上级不能直接复制超级

Wiki 对阈值实测明确写“超级确认，难度变化未确认”。

所以：

```text
Super = empirical-high
Beginner / Advanced = open
```

## 8. 人才府 fallback 的安全顺序

即便基础时间来自临时攻略表，人才府的处理可以精确：

```ts
baseDays = resolveResearchBaseDays(...)
finalDays = max(10, baseDays - 20)
```

这部分可以直接实现，因为减20与最低10都有PC地址证据。

## 9. 兼容 fallback

在原函数恢复前，如果引擎必须闭环：

```text
枪/戟/弩/骑/练兵：30/40/60/90
发明/防卫/火攻/内政：40/50/70/100
```

然后精确应用：

```text
人才府 -20日，最低10日
```

但这必须标 `compatibility-guide-fallback`，不是 confirmed-original，也不会模拟70/140/210/280动态变化。

## 10. E11 当前证据分级

### reverse-engineered
- 人才府精确 -20日；
- 人才府后最低1旬/10日。

### empirical-high
- 超级阈值70/140/210/280；
- 210无人才府30/40/60/90锚点；
- 210/280+人才府Lv1=10日；
- 280+人才府Lv4=60日；
- 由精确-20日反推280无人才府同一Lv4=80日。

### documented-guide
- 军事/练兵通常30/40/60/90；
- 发明/防卫/火攻/内政通常40/50/70/100；
- 攻略明确声明这些不是固定研究时间。

### open
- 完整PC研究时间函数；
- 超级五档×全部技巧完整矩阵；
- 初级/上级；
- 基础时长的数据来源；
- 属性getter层；
- 阈值比较符；
- Vanilla/主机版。
