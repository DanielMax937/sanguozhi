# E7 技巧系统

更新：2026-09-30。主目标版本：PC-PK1.1。补丁/版本差异留 E8 单独处理。

## 1. 系统结构

三国志11的势力技巧按“系”分组，每系4级，必须按级顺序研究。

无印已有8系：

1. 枪兵
2. 戟兵
3. 弩兵
4. 骑兵
5. 练兵
6. 发明
7. 防卫
8. 火攻

PK追加第9系“内政”。

PC-PK1.1 技巧ID连续为 `0..35`，每4个ID一系：

```text
0..3   枪兵
4..7   戟兵
8..11  弩兵
12..15 骑兵
16..19 练兵
20..23 发明
24..27 防卫
28..31 火攻
32..35 内政（PK）
```

结构化数据见 `docs/sources/techniques.json`。

## 2. 研究成本与研究人员

每一系第1～4级费用固定：

| 等级 | 技巧P | 金 |
|---:|---:|---:|
| 1 | 1000 | 1000 |
| 2 | 2000 | 2000 |
| 3 | 3000 | 5000 |
| 4 | 5000 | 10000 |

研究：

- 最多/固定选择3名执行武将；
- 消耗50行动力；
- 必须先完成同系前一级；
- 特技“指导”使研究金钱减半；
- 技巧点本身上限为10000。

PC地址：

```text
00481A97 / 00481A9C
004B64B8 / 004B64BF
技巧P上限 = 10000
```

研究完成后参与武将获得的对应能力经验与本次消耗技巧P相关：

```text
能力经验 = 消耗技巧P / 100
```

所以4级分别为：

```text
+10 / +20 / +30 / +50
```

对应能力：

| 系 | 研究经验对应能力 |
|---|---|
| 枪 / 戟 / 弩 / 骑 | 统率 |
| 练兵 | 武力 |
| 发明 | 智力 |
| 防卫 | 政治 |
| 火攻 | 智力 |
| 内政 | 政治 |

当前功绩表采用：

```text

```

日文Wiki旧“小ネタ”存在另一套1500/2500说法，因此功绩值继续标“主表高置信”，尚未恢复PC研究完成caller逐地址。

## 3. 研究时间：不能写成固定30/60/90/120

研究时间由3名执行武将的该系相关能力总和决定，并受难度、PK人才府影响。

当前已锁定的超级难度实测锚点：

```text
能力和分档：70 / 140 / 210 / 280
```

能力和≥210、无人才府：

```text
Lv1 30日
Lv2 40日
Lv3 60日
Lv4 90日
```

人才府固定缩短20日，最低不低于1旬/10日；例如Lv1可到10日。

能力和280且有人才府时，Lv4仍需60日，因此“每级固定30/60/90/120”以及“所有级别无条件-20”都不是完整研究时间公式。

仍 open：

- 70、140档完整矩阵；
- 初级/上级完整矩阵；
- 原研究时间函数体。

## 4. 枪兵系（ID 0–3）

### 4.1 枪兵锻炼 ID0

PC原伤害链确认：

```text
枪兵普通攻击 / 战法 / 支援攻击：
伤害倍率 ×1.10
```

这不是只强化“战法”。

### 4.2 兵粮袭击 ID1

原地址：

```text
005ADB55 techId=1
```

效果语义：枪兵攻击时掠夺敌方兵粮。

当前数值仍主要来自攻略实测：

```text
抢粮 ≈ 攻击力 × R，R∈[1,2]
上限还受自身兵力约束
```

因此效果存在已确认，但随机闭式继续标 empirical-high。

### 4.3 奇袭 ID2

森林中普通攻击时不受反击；该效果不等价于“所有战法都免反击”。

当前为稳定Wiki/攻略语义，尚未取得独立逐指令地址。

### 4.4 精锐枪兵 ID3

三层效果必须分开：

1. E3面板层：
   ```text
   基础攻击 +10
   基础防御 +10
   移动力 +6
   ```
2. 战斗伤害层：
   ```text
   普攻 / 战法 / 支援攻击 ×1.15
   ```
3. 与Lv1关系：
   ```text
   1.15 覆盖 1.10
   不是 1.10 × 1.15
   ```

## 13. 一个重要分层：面板强化与伤害强化不是同一件事

精锐枪/戟/弩/骑同时存在两层：

### 面板层 E3

```text
基础攻击 +10
基础防御 +10
移动 +6/+6/+6/+2
```

### 战斗伤害层

```text
锻炼：1.10
精锐：1.15
精锐覆盖锻炼
```

因此不能把精锐实现成：

```text
面板+10，然后伤害1.10×1.15
```

正确是：

```text
面板按+10重新算
伤害层只选1.15
```

攻城兵器/舰船的战法伤害也不自动继承枪/戟/弩/骑“锻炼/精锐”的1.10/1.15。

## 14. 技巧点数据层

技巧点：

```text
上限 = 10000
```

获得/扣除由各种动作独立调用势力技巧点增减函数，不应和“技巧研究成本表”混为一张表。

例如已确认：

- 训练：`floor(actualMoraleGain/2)+5`；
- 击破敌军：相关地址记录+25（地址资料常以“2倍参数50”表示）；
- 断盟：-50；
- 各种计略/开发/探索有各自分支。

E7只定义技巧系统与研究，不重新把全部技巧P获得事件重审一遍。

- 36个技巧ID及9系×4级结构；
- PK仅新增第9系32–35；
- 每级技巧P/金费用；
- 研究3人、50AP、同系顺序前置；
- 指导研究金减半；
- 技巧P上限10000；
- 研究能力经验=消耗TP/100；
- 各系对应能力；
- 绝大多数技巧的PC效果入口与关键数值；
- 精锐“面板+10”与“伤害1.15覆盖1.10”的双层结构；
- 熟练兵100→120、军制改革+3000、云梯1.4/1.2；
- 车轴+4、良马+4、木牛+3；

- 矢盾/大盾30%且原版默认不挡战法；
- 政令整备50%；
- 人心掌握精确2/3。

仍 open：

1. 完整技巧研究时间函数与非超级难度矩阵；
