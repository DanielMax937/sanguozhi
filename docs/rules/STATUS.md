E16 已撤回“普通击破统一武将伤亡率”。

PC-PK1.1 的武将 casualty 按来源分流：弩/井阑/舰船火矢、贯射、乱射走 `005974C0` 狙伤；猛者成功位移后50%负伤；业火种/业火球走 `00597350` 战死+独立负伤；骑兵与单挑继续使用各自专用结算。普通攻击、一般战法、设施攻击导致部队壊灭后，不再额外添加自拟 injury/death roll。

弩系狙伤公式为 `战法基础 + 统武比较档 + 性格 + 会心 - 1`，理论峰值6%。`0059753A = 0F 95 C1` 是 `SETNE CL`，确认会心+1有效。

业火以目标 `max(统,武,智)` 形成能力保护档；普通/高战死基础为2/4，再加性格减能力保护。无战死只跳过死亡，仍可炸伤。

本轮还修正“火矢不进业火函数”与“火矢不伤将”的混淆：火矢不调用 `00597350`，但弩/井阑/舰船火矢仍可进入 `005974C0` 狙伤。
