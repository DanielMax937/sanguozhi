# 规则覆盖状态

本规则包已覆盖原版/PK的主要**规则维度**：

- 时间/回合/难度/行动顺序
- 剧本初始化
- 地图/移动/ZOC/水战/港关
- 经济/内政/商人/行动力/灾害
- 武将生命周期/关系/忠诚/登用/俘虏/官职
- 征兵/生产/编成/训练/兵粮/补给/技巧
- 战斗/战法/攻城/火/异常/伤亡
- 战场计略/城市计略
- 外交
- 汉帝/爵位/继承/军团/灭亡/统一
- 事件/历史事件/遗迹庙
- 单挑
- 舌战
- PK 新系统与版本差异

## “完整”的定义

这里的“完整”是**系统维度已覆盖，且每个系统都有可实现的状态/指令/结果边界**。

它不等于“所有原作内部 RNG 公式已经反向工程到个位数精度”。尚未精确锁定的项目全部进入 `docs/rules/13-open-exactness.md`，并明确标记为临时采用/待实测。

这是比把猜测写成“确定规则”更适合工程实现的方式。
