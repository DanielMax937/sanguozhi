# 战场计略与城市计略

## 1. 战场计略（COMMON）

### 火计
- 气力 10。
- 对部队、设施、地面/火罠点火。

### 消火
- 气力 10。
- 熄灭火焰。

### 伪报
- 气力 15。
- 成功后目标撤向出兵据点。

### 扰乱
- 气力 15。
- 令目标混乱。

### 镇静
- 气力 10。
- 解除己方混乱等异常。

### 伏兵
- 气力 10。
- 需要适合的部队/地形；成功造成偷袭效果。

### 同讨/内讧
- 气力 20。
- 令相邻敌部队互相攻击；只作用于合法目标组合，不是所有邻军一起打。

## 2. 战场计略成功率

核心变量：

- 施计部队智力
- 目标智力
- 距离
- 特技：火攻、言毒、机略、诡计、虚实、神算等
- 看破/洞察/反计
- 鬼谋增加距离
- 百出降低气力消耗

当前 repo 的基础概率（火计70、扰乱50、伏兵60、内讧40、伪报45）属于“临时采用/实测拟合”，不等于已知原作内部常量。

## 3. 城市计略

必须至少包含：

- 流言
- 二虎竞食
- 驱虎吞狼
- 镇压/作敌等版本中存在的计略指令

### 流言

目标：降低敌城治安与武将忠诚，给后续登用/策反创造条件。

- `[PK]` 计略府使流言成功率绝对提高（现有 repo 采用 +15%）。
- 精确忠诚/治安扣减分布仍需实测。

### 二虎竞食

目标：破坏两个势力关系/制造冲突。成功获得技巧点/经验（现有经验表已有）。

### 驱虎吞狼

目标：策反敌势力太守/制造独立势力或内乱（具体触发依目标太守忠诚、君主关系、执行者能力等）。

> 当前 repo 仅记录了技巧点/经验，缺完整成功条件和状态转移。本规范要求将其实现为明确的外交/人物状态操作，而不是只发奖励。

## 4. 计略结果必须产出事件

示例：

- `StrategySucceeded`
- `StrategyFailed`
- `LoyaltyChanged`
- `PublicOrderChanged`
- `UnitConfused`
- `UnitFalseReported`
- `FactionRelationChanged`
- `GovernorRebelled`

这样才能用于存档回放和 AI 训练。
