# 战场计略与城市计略

## 1. 战场计略（COMMON）

### 火计
- 气力 10。
- 对部队、设施、地面/火罠点火。

### 消火
- 气力 10。
- 熄灭火焰。

### 伪报
- 气力 15。
- 成功后目标撤向出兵据点。

### 扰乱
- 气力 15。
- 令目标混乱。

### 镇静
- 气力 10。
- 解除己方混乱等异常。

### 伏兵
- 气力 10。
- 需要适合的部队/地形；成功造成偷袭效果。

### 同讨/内讧
- 气力 20。
- 令相邻敌部队互相攻击；只作用于合法目标组合，不是所有邻军一起打。

## 2. 战场计略成功率

### 通用优先级

`[COMMON][confirmed/empirical-high]`

- 洞察：敌方部队计略必看破。
- 看破：对智力较低者计略必看破。
- 规律：免疫伪报。
- 沉着：免疫扰乱。
- 明镜：免疫伪报与扰乱。
- 言毒/机略/诡计/火攻/虚实/神算等按特技描述提供条件必中。
- 倾国：普通计略成功率最终 ×2；**妖术、落雷不吃倾国**。

特技说明来源：
https://www.gamersky.com/handbook/200603/21610.shtml

### 伪报

`[PC-PK中心][empirical-high]`

设 A=施计部队智力/魅力，B=目标部队智力，C=目标是否已异常，D=目标智力高于施计方的额外惩罚，E=目标主将性格：

```
V1 = A智*0.3 - B智*0.2 + A魅*0.05 + E + 70 + C

V2 = A智²*(100-B智*0.9)*100/(A智²+B智²)/55
     - (100-A智)*0.1
     + A魅*0.05 + E - D + C

success = min(V1, V2)
```

其中：
- C：目标已异常 +10，否则 0
- D：若 B智>A智，则 `(B智-A智)/6`，否则0
- E：小心/胆小 +3，冷静 +1，刚胆 0，莽撞 -2

### 扰乱

`[PC-PK中心][empirical-high]`

```
V1 = A智*0.3 - B智*0.2 + B防*0.05 + E + 70 + C

V2 = A智²*(100-B智*0.9)*100/(A智²+B智²)/45
     - (100-A智)*0.1
     + B防*0.05 + E - D + C

success = min(V1, V2)
```

- C：目标已异常 +10
- D：若 B智>A智，则 `(B智-A智)/6`
- E：小心/胆小 -2，冷静 0，刚胆 +1，莽撞 +3

这也解释了为什么扰乱通常比伪报更容易成功。

### 落雷

`[PC-PK中心][empirical-high]`

`success = 施计智力 × 0.6 + 15 + abnormalBonus`

目标已异常时 +10。落雷不受倾国倍增。

### 来源

上述三条来自底层概率逆向资料：
https://www.ptt.cc/man/Koei/D802/D96B/D4AA/M.1371726847.A.536.html

### 仍未闭式确认

火计、伏兵、同讨/内讧、妖术的普通成功率尚未找到同等级可复算公式。

因此**删除旧的**“火计70%、扰乱50%、伏兵60%、内讧40%、伪报45%”统一基础概率。这套旧值只可作为早期模拟假设，不再是 canonical 规则。

### 战法成功率逆向表的冲突

同一逆向资料还给出一套战法基础成功率 + 适性 + 高低差/地形修正公式，但它与日文 Wiki 已长期实测的最终 S/A/B 成功率表存在约 5 个百分点差异。例如枪“突刺”：

- 逆向表：基础70 + A5 / S10（中性高度即 B70/A75/S80）
- 日文 Wiki：B75/A80/S85

因此该表暂不覆盖 `01-map/05-combat` 的现行战法表，列入 patch/version 回归项。

## 3. 城市计略

必须至少包含：

- 流言
- 二虎竞食
- 驱虎吞狼
- 镇压/作敌等版本中存在的计略指令

### 流言

目标：降低敌城治安与武将忠诚，给后续登用/策反创造条件。

- 官方PK手册支持200金/30AP、有期间，执行者智力越高及目标太守/君主/军师智力越低越容易成功；失败降低外交关系
- 公开 `005D02A0..005D05AD` listing先设参数10，计略府分支在 `005D04E3` 改为12。这个独立参数事实不等于固定“+15%/+20个百分点”，也不证明完整原成功概率已恢复
- `005BA410`、目标角色/名单helper、最终随机比较与RNG仍open；005D0540/005D055A的sar助记符宽度与旁列bytes存在文本冲突。不能把可见末段整数算术写成端到端完整原概率式
- `005D05B0 / 005D05F0`是两个独立后续函数，业务分工/body仍open；分层不证明哪个是selector、忠诚或治安loss
- 玩家百人城/300多次成功的观察反对“全城全员同步固定扣忠”，并有隐藏120→109记录；这些观察不恢复selector人数或loss分布，详见[41](41-nonnatural-loyalty-exactness.md)与[58](58-rumor-effect-helper-boundary.md)
- [O12-B独立标量服务](rumor-scalar-lifecycle.md)另以synthetic odds/三人平均防守、关系保护、至多一人加空槽、义理阈值及分离loss实现有限软件行为；10/12接入新权重也仍synthetic。其独立预算/旬序/RNG不接原世界命令
- 原被捕风险 unresolved-not-modeled，不是0；travel/failureDiplomacy/xpMeritTp未模拟、ownershipFrozen=true。原成功率仍E、完整原动作仍X；O12与原43不关闭，没有本批运行验收

### 二虎竞食

目标：破坏两个势力关系/制造冲突。成功获得技巧点/经验（现有经验表已有）。

### 驱虎吞狼

目标：策反敌势力太守/制造独立势力或内乱（具体触发依目标太守忠诚、君主关系、执行者能力等）。

> 当前 repo 仅记录了技巧点/经验，缺完整成功条件和状态转移。本规范要求将其实现为明确的外交/人物状态操作，而不是只发奖励。

## 4. 计略结果必须产出事件

示例：

- `StrategySucceeded`
- `StrategyFailed`
- `LoyaltyChanged`
- `PublicOrderChanged`
- `UnitConfused`
- `UnitFalseReported`
- `FactionRelationChanged`
- `GovernorRebelled`

这样才能用于存档回放和 AI 训练。
