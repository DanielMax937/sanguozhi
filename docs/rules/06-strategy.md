# 战场计略与城市计略

## 1. 战场计略（COMMON）

### 火计
- 气力 10。
- 对部队、设施、地面/火罠点火。

### 消火
- 气力 10。
- 熄灭火焰。

### 伪报
- 气力 15。
- 成功后目标撤向出兵据点。

### 扰乱
- 气力 15。
- 令目标混乱。

### 镇静
- 气力 10。
- 解除己方混乱等异常。

### 伏兵
- 气力 10。
- 需要适合的部队/地形；成功造成偷袭效果。

### 同讨/内讧
- 气力 20。
- 令相邻敌部队互相攻击；只作用于合法目标组合，不是所有邻军一起打。

## 2. 战场计略成功率

### 通用优先级

`[COMMON][confirmed/empirical-high]`

- 洞察：敌方部队计略必看破。
- 看破：对智力较低者计略必看破。
- 规律：免疫伪报。
- 沉着：免疫扰乱。
- 明镜：免疫伪报与扰乱。
- 言毒/机略/诡计/火攻/虚实/神算等按特技描述提供条件必中。
- 倾国：普通计略成功率最终 ×2；**妖术、落雷不吃倾国**。

特技说明来源：
https://www.gamersky.com/handbook/200603/21610.shtml

### 伪报

`[PC-PK中心][empirical-high]`

设 A=施计部队智力/魅力，B=目标部队智力，C=目标是否已异常，D=目标智力高于施计方的额外惩罚，E=目标主将性格：

```
V1 = A智*0.3 - B智*0.2 + A魅*0.05 + E + 70 + C

V2 = A智²*(100-B智*0.9)*100/(A智²+B智²)/55
     - (100-A智)*0.1
     + A魅*0.05 + E - D + C

success = min(V1, V2)
```

其中：
- C：目标已异常 +10，否则 0
- D：若 B智>A智，则 `(B智-A智)/6`，否则0
- E：小心/胆小 +3，冷静 +1，刚胆 0，莽撞 -2

### 扰乱

`[PC-PK中心][empirical-high]`

```
V1 = A智*0.3 - B智*0.2 + B防*0.05 + E + 70 + C

V2 = A智²*(100-B智*0.9)*100/(A智²+B智²)/45
     - (100-A智)*0.1
     + B防*0.05 + E - D + C

success = min(V1, V2)
```

- C：目标已异常 +10
- D：若 B智>A智，则 `(B智-A智)/6`
- E：小心/胆小 -2，冷静 0，刚胆 +1，莽撞 +3

这也解释了为什么扰乱通常比伪报更容易成功。

### 落雷

`[PC-PK中心][empirical-high]`

`success = 施计智力 × 0.6 + 15 + abnormalBonus`

目标已异常时 +10。落雷不受倾国倍增。

### 来源

上述三条来自底层概率逆向资料：
https://www.ptt.cc/man/Koei/D802/D96B/D4AA/M.1371726847.A.536.html

### 仍未闭式确认

火计、伏兵、同讨/内讧、妖术的普通成功率尚未找到同等级可复算公式。

因此**删除旧的**“火计70%、扰乱50%、伏兵60%、内讧40%、伪报45%”统一基础概率。这套旧值只可作为早期模拟假设，不再是 canonical 规则。

### 战法成功率逆向表的冲突

同一逆向资料还给出一套战法基础成功率 + 适性 + 高低差/地形修正公式，但它与日文 Wiki 已长期实测的最终 S/A/B 成功率表存在约 5 个百分点差异。例如枪“突刺”：

- 逆向表：基础70 + A5 / S10（中性高度即 B70/A75/S80）
- 日文 Wiki：B75/A80/S85

因此该表暂不覆盖 `01-map/05-combat` 的现行战法表，列入 patch/version 回归项。

## 3. 城市计略

必须至少包含：

- 流言
- 二虎竞食
- 驱虎吞狼
- 镇压/作敌等版本中存在的计略指令

### 流言

目标：降低敌城治安与武将忠诚，给后续登用/策反创造条件。

- `[PK][PC-PK1.1 reverse-engineered]` 计略府确实提高流言成功率，但不是固定“+15%”或“+20个百分点”。
- 原 `005D02A0` 流言成功率函数先设内部参数 `10`；若执行者所在城市存在计略府（设施 `0x2C`），则在 `005D04E3` 改为 `12`。这个参数继续进入后面的完整概率式。
- 因此准确实现应是“**流言公式参数 10 → 12**”，而不是最后对 UI 成功率直接加常数。
- 当前没有源码证据证明计略府同时提高二虎竞食、驱虎吞狼等其他城市计略的成功率。
- 成功率与效果结算必须分层：公开逆向还标出 `005D05B0 / 005D05F0` 两个流言相关 effect-side helper，但函数体未展开。
- P0-6 已用大样本实测排除“成功一次就给全城所有武将统一扣固定忠诚”的模型；原作效果必须保留目标武将 selector 与单人损失 RNG。忠诚隐藏值>100同样会被流言向下削减。
- 流言成功后的 target selector、忠诚损失和治安损失精确分布仍 open，详见 [41-nonnatural-loyalty-exactness.md](41-nonnatural-loyalty-exactness.md)。

### 二虎竞食

目标：破坏两个势力关系/制造冲突。成功获得技巧点/经验（现有经验表已有）。

### 驱虎吞狼

目标：策反敌势力太守/制造独立势力或内乱（具体触发依目标太守忠诚、君主关系、执行者能力等）。

> 当前 repo 仅记录了技巧点/经验，缺完整成功条件和状态转移。本规范要求将其实现为明确的外交/人物状态操作，而不是只发奖励。

## 4. 计略结果必须产出事件

示例：

- `StrategySucceeded`
- `StrategyFailed`
- `LoyaltyChanged`
- `PublicOrderChanged`
- `UnitConfused`
- `UnitFalseReported`
- `FactionRelationChanged`
- `GovernorRebelled`

这样才能用于存档回放和 AI 训练。
